# R／R0 实际开发结果：独立复算与研究决策

2026-09-16。**本轮获得了更高的开发集 GMO IoU，同时加重运动目标漏检；没有得到 D 位移连接的可辨认增益，尚未达到“超过 O 且运动预测更准确”。** 应保留全部结果和 O，把后续问题转向运动状态如何被观测、监督并进入未来预测状态，而非再叠一层冻结 O 输出修正器。

## 实际核算范围

独立读取 `server_results/training/future_feature_residual_train_v1/development_records.jsonl` 的全部 200 条记录／100 scenes，核对 complete 绑定的四个小文件；按原始整数计数相加，重算三模型五时域 `2×2` confusion、四时域 `4×4` transition confusion、八组 GT/TP/FN，以及相应点估计。逐条检查原生与共同 confusion 相同、模型间 GT 分母相同、八组构成全部正类、t0 相同。所有总计与已冻结汇总精确一致，浮点点估计差不超过 `1e-12`。

## 重要修正：vacating IoU 下降不等于真实腾空漏检增加

`10` 指固定体素在 t0 为前景、未来为背景，必须两端都预测正确；本轮 t0 保留 O，其中已有误报。对 GT 为 `00` 的位置，若原预测为 `11`，把未来误报纠正为背景会得到预测 `10`：未来 occupancy 变好，但 transition 产生 false-10。

独立相加四 h 的原始 transition 矩阵：

| 相对 O | GT10→pred10 的 TP 变化 | GT00→pred10 的 FP 变化 | GT01→pred10 的 FP 变化 | GT11→pred10 的 FP 变化 |
|---|---:|---:|---:|---:|
| R | **+19,430** | **+1,003,699** | +30,790 | +44,739 |
| R0 | **+5,370** | **+914,067** | +26,266 | +29,993 |

GT10 支持不变，因此四 h 总计真实腾空 FN 反而减少；宏平均 vacating IoU 下降主要伴随固定错误 t0 引起的 false-10 增长，不能写成“物体残影增加”或“腾空能力已证更差”。保留原指标和全部矩阵，不通过改 t0／mask 消除此现象。arrival 的差区间跨零，也不能写成已证改善。这个解释不会抵消独立存在的 moving FN 增长。

## 这些结果定位了什么

1. **新增预测器的 GMO 收益不需要 D 运动连接。** R0 已在同样训练配方下得到更大的点估计增益；R−R0 没有正向可辨认增量。这排除了“观察到的 GMO 上升足以证明显式物理运动被有效利用”的论证，但区间跨零不等于证明两者等效或 R 完全忽略运输特征。
2. **此前 J/D 与本轮一致指向任务收益和运动收益的分离。** J−D GMO 仅 +0.002463 pp，区间跨零；J 的 moving 材料点平均 EPE 每 h 略高于 D，而两者共同 moving recall 都低于 O。本轮增加未来稠密上下文并允许 W=0 修正后，GMO 改善更大、moving recall 损失也更大。不能再将旧概率载体或 W=0 不可改写视为唯一解释；这些限制的解除并未带来所需运动增益。
3. **物理运动并未被整体否定。** 固定 train16 的部分真实位移替换仍使 D 的 GMO +0.234675 pp、moving recall +0.858721 pp，表明特定合法源上的位移纠正有价值。它与当前结果并不冲突：更准确的位移可能有用，但现有可观测状态估计、源支持、消费者和训练目标尚未把这种价值实现为运动收益。
4. **没有定位到唯一病因。** 原 O／D 均冻结，R/R0 共用同一当前 hard source；本轮没有独立操纵源支持、位移质量、物体对应监督或占据目标。不能据此宣布 O 表征不含运动、D 的位移毫无用处、原 O loss 必然错误、存在梯度冲突，或所有特征搬运均失败。结论只覆盖这个 41,137 参数预测器、512 次更新、seed11 和已有训练／开发分布。D 未更新，当然不能声称物理 EPE 改善。

## 下一步应改变什么判断

**不要重复既有 CV 表；新的同支持比较现已由 CPU 诊断补齐。** `train_motion_distribution_v1` 已分析 train512：2 s 的 11,750 个共同有历史对象上，零／历史 GT-CV 的中心 XY 误差为 2.4880／0.4971 m；旧 train16 七条件里也已有 `cv_O0` 传播，future GMO 17.7775%。旧 CV 使用历史可用源且仅平移，未来 oracle 使用另一有效集合并含旋转；D 的现有 EPE 是框材料点误差。这些旧数值不能直接作 D−CV 差值。

有价值的新问题是：**给定同一合法物体和源点，D 丢掉了多少仅历史状态已包含的运动信息；这些误差与 O hard source 缺失如何相交？** 新 `history_state_predictability_diagnostic_v1` 没有发现现成 train16 的 D 逐对象误差，因此实际采用已暴露 dev200 的认证标量记录与同一 `future-valid ∩ history-available` 稀疏材料点集合，没有新模型前向。在名义 2 s、共同 1,192 个 moving anchor×instance／129,919 个源点上，D／历史 CV／零位移的对象等权平均 XY EPE 为 **4.148792／1.185450／7.489120 m**。所有组共同支持为 3,723 个对象；另外 126 个有未来有效源但缺历史的对象单列，没有把它们填零或并入共同均值。CV 的速度只由 t0 与最近有效历史框的真实时间差求得，以名义 horizon 外推并转入 t0 R；未来 dt、框和目标不进入预测函数。它只平移，不估计角速度。

这个实际差距使**历史状态估计、时间对应和状态监督**比继续给 D 增加消费者更值得优先。GT 历史是特权标注，结果并不证明真实传感器或 O latent 已能恢复这些状态。新诊断没有同点 O hard-positive 掩码，尚未回答误差与 source 缺失的交集；也没有给出 CV 的同消费者占据分数。因此不能把差距直接换算成可达 GMO 增益，或认为只要把 CV 接进现有预测器就能解决问题。这里已阅读实际预测／同支持评分代码并核对 JSON 中的支持与点估计，未重新运行这项诊断，也未重算其全部标签。

**下一条优先结构检验是把物理监督直接连入原未来状态，而不是先引入对象 queries／Hungarian 配套系统。** 两臂都从 O 出发，解冻同一个 `future_pred_head`、继续同一 CE＋Lovasz，并配相同容量的源点位移读出器；一臂允许物理误差反传到未来状态，另一臂只对辅助读出输入 detach，读出器本身仍学习，occupancy 路径两臂均正常更新。固定初始状态、样本顺序、更新数、优化器参数范围和原标签后，差异回答的是“训练未来状态时加入物理监督梯度有无额外效果”。它比一次新增对象发现、匹配、查询交互和损失的路线更容易解释，且无需以 GT 物体框裁取测试输入。

这与旧 J/D **不是同一个干预**：旧 J/D 冻结 O，测试占据误差是否进入外部运动预测器；新方案测试物理误差是否塑造 O 的未来预测状态，梯度方向和被训练模块都改变。它仍是辅助任务连接的对照，不能仅凭阳性就声称学到了物理世界模型，或把已常见的辅助运动头包装成创新。

实施上有四个必要的解释约束：

- 源点定义和未来状态采样只能依赖当前／历史输入及原模型已有的已知几何条件，不能按 GT 未来位置取特征后称为预测；位移目标仍是固定 t0 R 的米制材料点对应，不能把 source-grid 索引直接解释为 future-frame 物理对应。未来框／教师特征只作目标，教师 stop-gradient。
- 两臂辅助头须都在所有原合法源点上监督，不能只给 O 当前 hard-positive 的点打标签而复制造成漏检的盲区；这不要求把 GT 源 mask 输入预测器。辅助头只用于训练时，它的有无不能改变初始 O 的 occupancy 前向。
- 验证物理 loss 确实能到达生成未来状态的 transition 参数，而非只更新辅助投影层。如果末层零初始化，首次上游梯度为零是正常现象，应在读出器已更新后检查；不要把这一正常现象误判为断路。即使有非零梯度，读出器仍可能主要依赖当前状态捷径，不能据此证明未来状态被有效使用。
- 若辅助物理 EPE 改善而 GMO／moving recall 没有改善，说明读出或状态更适合该代理监督，尚未证明占据任务利用它；若只有 GMO 变好且 moving FN 增多，则仍是当前的风险权衡。阴性也不能排除历史输入不足、冻结前端丢信息、监督权重／可训练预算不足或对象对应表征的价值；它只否定本次连接的实用效果。

该路线仍是待验证假设；现有同支持 CV 差距支持优先研究状态估计与监督，但不足以证明解冻未来 head 必能补回传感器信息。对象 queries／Hungarian 路线应在需要显式实例分解或对应、且其输入信息和成本能说明时再考虑，不能把增加模块复杂度当作修复机制。R/R0 可以保留为占据 IoU 分支，但不应因开发 GMO 正结果自动晋级为运动研究成功；若支付 full5119 成本，其问题应明确是验证原任务收益，而非用更大评价集修复已出现的机制与运动证据缺口。不改本轮指标，不新增事后成功门，不启动新的训练。
