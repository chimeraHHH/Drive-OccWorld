# 既有 CRN 对象状态的同材料点恒速诊断

本约定在读取该诊断的任何新误差分数之前固定。上一项 K/B 训练和 dev200 已完成且不具共同占据/运动收益，保留 O/M0。下一问题是：先前只有历史真值状态可用时表现较好的恒速预测，能否由一个现成传感器模型给出的对象状态部分实现？本轮不训练、不执行新检测推理、不读取 CRT 新结果。

## 输入和前向定义

仅使用已完成 CRN 官方权重推理的 `results_nusc.json`。既有完整导出 SHA 为 `fec6541461bf6eb0ad5f3e113e4fcb13c937896731203ef5de003a6ac0055653`，6019样本、2826237框；提取固定 selection_v1.json 的全部200开发token，保存它们的全部原预测。框中心/朝向/速度由原导出定义在global坐标；官方 `det_evaluators.py` 对ego预测Box施加ego2global旋转和平移后输出global中心、wlh、wxyz和XY速度。

场定义只接预测框、当前参考LiDAR到global的G0和任意查询坐标，不接GT对象身份、真实未来位姿/位置/时间。对每个点p0，转至global并判断其是否处于某个预测GMO框内，包含面容差沿既有几何1e-9米；八类固定car/bus/truck/trailer/construction_vehicle/motorcycle/bicycle/pedestrian。选择包含该点的最高原detection_score框，分数相同保留原export顺序；没有新增分数阈值、类别权重或GT匹配。原导出已有其官方后处理阈值，不称完全无阈值。

该框的global平面速度扩为[vx,vy,0]，只用G0的逆旋转变到R；未覆盖点速度为零。名义0.5/1/1.5/2秒位移等于h乘该R速度，没有加未来ego位姿、角速度或真实未来dt。采样只在已有sparse源坐标上执行等价于查询上述全空间解析场；GT仅决定既有评价支持和误差，不参与构造预测场。

## 同支持评价

保留原200 anchors/100scenes、原16074对象-时域对和其全部合法唯一材料点，不按检测成功、分数、覆盖或误差筛选；原缺标注和无唯一源点支持缺口继续披露。XY/XYZ点EPE先按对象平均，再按anchor-instance等权，给出四时域与all/stationary/ambiguous/moving的mean/median/p90。使用原complete的D逐对象EPE作为对照；不为O虚构flow。

比较CRN-CV、D、zero的完整同支持均值，保持相同100场景与10000次seed11场景配对bootstrap，报告均值差95%区间。覆盖统计另列每组点覆盖率、对象部分/全部/无覆盖数量，以及覆盖/未覆盖的CRN-CV和zero误差。没有D逐点预测，不能从D对象平均EPE反推覆盖子集D指标；覆盖子集不能替代完整结果。

使用原raw/sparse标签及其SHA，不重生成标签。source/selection/label/Dcomplete与全部记录身份、点数须核对；新数据若无法满足此合同，应定位具体原因，不自动改标签/删样本。代码执行前核查必要的向量旋转、wlh轴与重叠排序、未覆盖零值三项CPU几何案例；仅为几何正确性检查，不是性能证明。

## 结论边界与后续动作

若包含漏检的全支持结果仍明确优于D，可优先研究对象状态恢复及其与占据生成的有效连接；若收益仅在覆盖部分，优先解决状态覆盖，不能把筛选结果作为部署性能。若整体不佳，需结合覆盖、已覆盖误差和恒速假设区分下一诊断，不能据此说原传感器缺少信息。任何结果均不能单独证明原生O占据改善、K/B未来特征无信息或新颖性。

CRN是额外的官方检测模型，官方配置注释报告约6140万参数，具有对象监督和四个keyframe输入。配置中的索引为[0,-2,-4,-6]；若候选历史索引不属于当前场景，官方数据集将索引向后推进，直到到达同场景的可用帧，不一定回退到当前帧。它与O的历史/任务/监督预算不同。本诊断用于查清可用对象状态的价值，不把这种差异隐去作为同容量模型胜出。保留单seed实验限制，不触发多种子训练或恢复S3。
