# J/D：联合运动与占据训练的执行决策

2026-09-16，北京时间。前一轮是实际进展：A/Z 完成各 512 更新，共同 dev200 完成并通过根任务逐样本原指标复算。目标仍为超过固定 O，且运动预测更准确；没有完成声明。

## 新证据改变了什么

A 相对 O 的未来 GMO IoU 为 +0.086514 pp，场景配对 95% CI [0.032389, 0.139570]。01/10 占据变化 IoU 分别提高 0.238071/0.166161 pp。但是，按真实框端点速度 >0.5 m/s 归属的 GT 正体素召回率下降 0.826871 pp，CI [−0.962566, −0.697468]，四个时域各自都下降。全域 FP 减少 248032、FN 增加 20546。计数来源为 `common_change_dev200_v2_pooled.json`，原 200 个 O/A/Z 混淆矩阵与训练后独立评价逐一精确相同。

这支持一项小的开发集占据改进，不支持统一运动改进；召回下降也不能独自证明位移场变差，因为门、概率和硬决策同时影响召回。A 的 motion head 本来就冻结，物理场并没有被占据任务更新。此时直接启动全量长评测或给 O 拟合一个新监督读出，都不能回答当前最直接的训练机制问题。

## 执行范围与唯一有意差异

实施既有提案的 J/D 配对，复用固定 O、source_motion_train_v1 最终 motion head、预测前景支持与 97 参数融合门。两臂均从同一个运动权重和同一个新门初始化开始，运动头都继续接受原刚体框材料点监督。J 允许占据损失通过传输更新运动头；D 仅在送入传输处使用 `d.detach()`，并保留原 d 的运动监督。O 完全冻结。

联合目标固定为 `L_occ + 1 m^-1 * L_motion`；物理项仍为原 beta=0.5 m SmoothL1、点坐标平均→对象平均→存在速度组平均→有效时域平均，原六项 CE[1,5]+Lovász 不变。单位系数是一项明确固定的训练选择，不是等梯度、最优系数或开发集调参的证明。预检记录两项在同一状态下的真实梯度量级与夹角；不据 dev 成绩搜索系数。

固定 seed11、原 512 训练 anchors×4 passes、accum4、每臂 512 更新。motion AdamW peak lr=1e−4、末 lr=1e−5、clip10；gate peak lr=1e−3、末 lr=1e−4、clip35；两者均 warmup25、原 cosine、wd=.01、beta=(.9,.999)、eps=1e−8。motion/gate 使用分离 optimizer 与 clip 组，两臂顺序、初值、学习率和预算匹配。预训练 motion 的 optimizer 不恢复。原 A/Z 最终门不作为初值。

先以固定顺序前 16 个训练样本进行 4 次真实更新预检，无 dev、不保存可复用权重；预检通过后重新初始化正式训练。源码和运行预算在派发前另写冻结 JSON 并绑定哈希。运行使用现有 detached server runner，保留失败记录，不因观测超时重启。

## 必須先证明的实际连接

在初始固定训练样本上，用同一次传输数值建立 J 与完全 detach 的 D 分支，验证前向一致、J 占据到 motion 的参数梯度非零有限、D 该梯度为 None、两侧物理监督梯度一致。该同值 VJP 是连接验证，不替代两臂实际独立 scatter 的训练路径。

重复 CUDA scatter 可能有归约舍入；独立初态 forward 固定用 rtol=1e−5、atol=1e−6 检查并记录最大差。t0、O 状态、观测输入、未覆盖输出等原有字节门仍严格。保留原十二项损失有限值审计，恒定 CE 比较沿用已冻结 v2 容差，恒定 Lovász 精确；不修改实际损失值。原生缓存读取 GT 是监督流程的一部分，GT 不得进入运动／融合输入。

## 结果与停止条件

固定最终 dev200 同时报告 O/J/D 原任务 IoU、四时域、t0、FP/FN，以及 J/D/原预训练 motion/zero 的同支持 XY/3D EPE、三个速度组、均值/中位/p90和分母。O 无物理 flow 输出，不能伪造 O 的 EPE；后续仍需共同输出的运动对象预测风险和完整 5119 原任务验证。

J 胜 D 但不胜 O，仅证明这项连接政策有局部作用。J 的占据改善而物理 EPE 退化，最多支持任务纠错场有用，不能称物理运动更准。两类结果均不改善，则结束本预算的直接概率传输扩展，将传输表示／空间解码作为下一项独立科学因素；不靠更多种子、筛时域或改阈值延续这一候选。单一固定系数负结果不构成否定一切联合训练。

输出式 motion readout 的八项实际 CPU 测试已经通过，但目前只有模块，没有缓存生产、训练或模型结果；保留为需要时的辅助诊断，不作为此轮主要工作或目标替代。

## 文献对该决策的约束

新增核对 [Occupancy Flow Fields 原论文](https://arxiv.org/pdf/2203.03875) §III-F 与表 I。作者用 flow-trace 损失连接占据与运动；其表中部分占据/轨迹一致性指标提高而一步 EPE 变差。因此“任务连接一定使物理 flow 更准”没有文献保证。作者对标注噪声的解释不能直接套在本项目；我们仍如实评价固定原标签上的退化，不以无法验证的真运动解释消除负结果。

该工作的 flow 位于目的帧并指向前一帧，以网格为单位；我们的位移位于 t0 源点、指向四个未来、以米为单位。[官方 metrics 实现](https://github.com/waymo-research/waymo-open-dataset/blob/master/src/waymo_open_dataset/utils/occupancy_flow_metrics.py)中的 occupancy AUC/soft IoU/flow EPE/flow-traced 评价是不同量，不能将新 EPE 或 trace 分数替代原 fine-GMO IoU，也不能把无 flow 的 O 直接送入 flow metric。

先前已经按作者代码核对的 FipTR、Softmax Splatting 和 TOFlow 提供可导连接、传输表示与任务 flow 的先例，详 `connected_motion_next_decision_v1.md`。本轮不复制第三方训练配方或启动第三方训练。
