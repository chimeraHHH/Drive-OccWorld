# V/G 揭晓前结果判读规则

2026-09-16。**这是解释规则，不是新增晋级阈值或正式协议。** 两份统计器已完成并停止修改；V/G 原生预检和正式结果尚未产生。以下“改善”须同时呈现实际差值与既定区间，不以显著性替代效应大小，也不把区间跨零写成效果恰好为零。

## 固定回答三个不同问题

1. **原任务是否优于 O？** 使用原四个未来时域各自池化完整 confusion 后的 GMO IoU，再取四时域均值；并列全部五时域、全局 FP/FN、八个运动归属组、transition 与 t0 代价。V−O、G−O 包含继续训练、新容量和额外 CRN 状态输入，不能单独归因于预测速度。
2. **物理位移是否更准确？** O 没有原生 flow，不能造出“O 的 EPE”。参照是冻结 D、固定 CRN-CV v2 和零位移；对原全部 16,074 个对象—时域支持比较四时域 moving 组及其余组的 XY/XYZ mean、median、p90。每对象内源点误差先平均，再按 anchor-instance 等权。EPE 差为负才是改善；不能把零位移对照、动态召回或 IoU 当成 D/CRN-CV 比较的替代品。
3. **速度输入是否有增量？** V−G 固定框几何、类别、置信度、容量、损失及训练预算，只改变速度槽及其派生未来中心。它识别的是该实现与预算下速度输入的增量；不证明唯一内部表征机制，也不证明其他状态连接无效。共同提升而 V≈G，不足以支持速度机制。

## 所有分支共同保留的解释限制

- 不删未检测覆盖的对象；CRN-CV 对未覆盖点仍为零速度。原 sparse 的无唯一当前源点、缺未来标注等既有缺口必须披露，未来出 ROI 的有效位移标签仍计入。物理量是 box 刚体虚拟材料点代理，不是实测 scene flow。
- 占据与物理使用不同但固定的支持集合，不能以较小的物理有效集合裁剪原完整占据评价。moving recall 配合全局 FP/FN 说明动态占据覆盖，不能单独证明位置或物理位移更准。
- V/G 更新整个 future-head，t0 可以变化。transition 比较的两个预测端都在变；arrival/vacating 的改善或下降不能直接归结为物理运动变化。报告 t0 代价，但不事后新增“每时域均不下降”门。
- 完整保留四未来时域与所有原分组，不事后挑 2 秒、moving 子集或某一种误差描述量。mean 的场景成对 10,000 次 bootstrap 与 median/p90 描述量分开；空分母保持 null。区间未作多重比较修正，单训练 seed11 的场景区间不代表训练种子不确定性。
- dev200 的 100 场景已有历史暴露；结果是受控开发证据。CRN 额外感知容量、预训练、历史输入与推理成本需披露。是否开展完整验证由全部真实结果和原用户联合目标决定，不从本表生成自动 pass 字段，也不据后续诊断改写本轮标准。
