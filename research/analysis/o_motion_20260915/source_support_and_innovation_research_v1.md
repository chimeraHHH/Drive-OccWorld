# 从真实 J/D 结果到源支撑与未来占据生成

2026-09-16。只读实际结果、现有融合模块和两篇新增一手文献；未运行模型或训练。下面审的是 partial-oracle 的科学设计，不把尚未执行的诊断写成结果，也不替代其实现审查。

## 真实结果约束了什么

固定 final512、dev200／100 scenes，未来四时域各自池化后平均；下表为百分点及 10,000 次 seed11 配对 scene bootstrap 的未校正区间。

| 对比 | 原 GMO IoU 差 [95% CI] | GT 水平端点速度 >0.5 m/s 的 recall 差 [95% CI] |
|---|---:|---:|
| J−O | +0.093615 [+0.037532,+0.148205] | −0.903700 [−1.061069,−0.756514] |
| D−O | +0.091152 [+0.039412,+0.142530] | −0.916112 [−1.065686,−0.773207] |
| J−D | +0.002463 [−0.004672,+0.009719] | +0.012412 [−0.019802,+0.044269] |

J、D、O 的 moving recall 分别为 42.548422%、42.536010%、43.452122%。`annotated_future_only` recall 为 11.687598%、11.729329%、12.547239%；J/D 对 O 的差分别 −0.859641／−0.817910 pp，区间均低于零。它指原始标签里未来有框但当前及所查历史无框，**不等于已经认证的物理出生或遮挡解除**；进出标注范围、标注缺失等仍可能参与。`t0_missing_with_history` 支持很少，不能由其零 recall 推广总体结论。

与此同时，J−D 的 moving XY EPE 在 0.5／1／1.5／2 s 为 +0.004632／+0.006816／+0.009264／+0.014712 m，各均值差区间下界均大于零；2 s 为 J 4.222952、D 4.208240、预训练 P 4.358820 m。占据梯度在当前系统留下了小的物理代理误差代价，没有可辨认的额外占据或动态 recall 收益；不能把它说成普遍梯度冲突、两模型等效或物理流已被严重破坏。EPE 是物体内源点平均后按 anchor-instance 等权的刚体框代理，recall 是未来 GT 体素统计，两者分母不同。历史 dev 已暴露，区间不包含训练 seed 方差。

## 冻结 D 的 partial oracle 能识别的范围

将位移替换限定在原 sparse label 的 `valid[h]` 源 flat indices，所有未替换位移逐位不变；O 当前概率、argmax 源 mask、载体、D gate 参数及原完整 GT 评价不变，是一个合理的**固定系统位移干预**。必须分别记录有效标签点数、其中 O 当前前景点数，以及实际改动位移数；`valid` 但 O mask 为 false 的点不会搬出任何概率质量。

冻结 gate 参数不等于冻结 gate 数值：其输入含搬运概率和 W，替换位移后重新计算 gate 是现有系统的正常响应。因此测得的是位移修正经过固定融合函数后的总效果，不能只归因于落点几何。

潜在影响域应为 `I_h = interpolate(float((W_D>0) OR (W_oracle>0))) > 0`，复用冻结 `fine_binary` 的实际 `[N,1,X,Y,Z]→(512,512,40)` trilinear、`align_corners=False` 路径。不能仅取 oracle W，否则原落点被移走的变化会错归为域外。该域是局部门及插值的保守依赖范围，**不是可见性、正确实例对应、物理可达率或新增的评价 mask**。原 moving GT 的 FN 在域内／域外相加必须恢复原总数；域外两预测应完全相同。域内仍可能有大量未受实际改动的点，不能以域内 FN 都是 flow 错误。

正结果只说明：在这 16 个训练 anchors、有效原始刚体对应、预测源支撑和固定融合下，纠正该子集位移具有作用；它不是完整真 flow 上界，更不是可部署候选。负结果不能排除运动信息有用，因为源漏检、未监督背景、重叠／缺帧、新显露对象和融合函数都未改变。该设计也**不能区分“换成特征搬运”与“增加独立未来生成能力”**，不应据其单次正负直接选模型。

## 两篇新增一手依据

**STrajNet（ICRA 2023）**：原论文 §III-A/D/E、式(4–7)用历史对象栅格／地图／轨迹和 flow，经可学习 offset 采样特征，再解码未来 observed、occluded occupancy 与 flow；occluded 输出并非当前 hard mask 的平移。报告单独 occluded AUC／soft-IoU 和 flow EPE，但不是我们 3D GMO／速度分组。其内部采样 offset 不等于独立验证过的物理位移。[论文 pp.2–5](https://arxiv.org/pdf/2208.00394)。作者代码有明确两类 occupancy 的监督与独立 flow 输出；但固定 master 的 `FG_MSA.py:141–142` 刚算出的 `x_sampled` 随即被原 x 的 reshape 覆盖，且 `train.py:194` 未开启默认关闭的 `fg_msa`，不能把默认入口当论文模块复现。未核到 LICENSE 或发布权重。[仓库](https://github.com/georgeliu233/STrajNet)，[固定采样源码](https://github.com/georgeliu233/STrajNet/blob/21884df0ea34c725f970c26267eb191fa3c9e8f6/FG_MSA.py#L106)，[训练入口](https://github.com/georgeliu233/STrajNet/blob/21884df0ea34c725f970c26267eb191fa3c9e8f6/train.py#L193)。这只是所核字节的静态事实，不是论文结果反证。

**ImplicitO（CVPR 2023）**：§3.2/3.3 用时空 query 从 LiDAR＋HD map 特征读取局部与远处证据，再分别输出 occupancy 与 backward flow；BCE 加 0.1×前景框刚体 L2，attention offsets 无直接物理监督。它不要求 query 已被当前检测判成前景；表2用同编码器比较 decoder，表3比较有／无 offset。由此支持“先取稠密上下文再解码”的设计依据，而非证明所有缺源对象都可恢复。其 AV2 标签用 CTRA 补齐缺失轨迹，未单列本项目 future-only 分组；不可移植该补标来改善我们的评分。只核到作者论文／项目页，未核到公开实现和权重。[正文 §3–4、附录A](https://arxiv.org/html/2308.01471v1)，[作者项目](https://waabi.ai/research/implicito)。物理输出与任务采样 offset 分设已有先例，不能当作本项目新的分离思想。

## 最有依据的下一方法方向：用运动访问证据，由稠密上下文生成占据

**待验证假说**：主要约束可能是 hard-positive 概率载体和局部凸混合的表达范围，而不仅是位移精度。当前 `supported_motion_fusion.py` 在 W=0 保留 O；W>0 时输出是 O 与运输 logit 的凸组合。因此两者都低于零时，任何 gate 都无法产生前景；没有源的对象也不能仅靠移动其他概率获得正确身份证据。这里是模块的数学边界，不是全部真实漏检已被归因于它。

优先方向是保留 O 原预测作为零初始化基准，使用**O 的稠密未来特征、当前观测特征的运动搬运结果和支持量**，训练可以正负修正的空间 decoder；让未来预测访问未超过当前 argmax 阈值的观测信息，并允许无运输支撑处由稠密上下文生成占据。首轮固定 D 的物理位移头，把它当对应建议而非可任意改写的概率流，不再直接给它占据梯度。沿现有输出参考系 R 和已有映射，不改 O 内部坐标；父任务已核实可 hook 原未来 256 维特征，不需要新增视觉 backbone。此方向尚未实现或验证，feature warp＋refinement 本身已有强先例，不够构成新颖性。

必要的首个训练比较只有**同一 decoder／相同稠密输入，在连接处使用 D 位移或置零位移**：两臂同参数化、初态、原 O／D 权重、训练 anchors、seed11、更新数与原占据目标；物理头均冻结。不得给任何分支输入 GT source mask、未来框、真实未来图像或新的地图。原 O 保留作容量外基准，零位移臂控制新增上下文／decoder 本身的收益；只有运动臂进一步提高共同 GMO 与 moving／future-only 表现，才支持运动访问证据的增量作用。它仍不能单独证明特征载体优于概率载体，后者需要另外的匹配表示对照。先实际预检成本后再定预算，不把该设想作为续训或启动授权。
