# 历史运动—未来收益连接：真实结果与决策

**当前证据支持优先修正观测对应，而不是继续给简单 ZNCC 分数增加门控或 loss。** 历史刚体代理收益与未来收益有较强关联，但现有图像分数连过去收益也不能有效排序。这是 train512 内部诊断，不构成可部署方法、因果唯一定位或超过 O 的结果。

## 1. 实际执行与定义

CPU 分析实际耗时 **17.479 s**，完成 512 个训练样本／256 个场景。未调用 GPU、模型、优化器或重新采样图像。

复用此前已经冻结的 D、图像得分和 source 材料点。由同一 GT instance 的当前与上一关键帧框姿态重建历史刚体位移：

`H(p) = inv(G0) Aprev inv(A0) G0 p − p`

`Dpast = (tprev − t0) · vD`，其中 `vD` 为原四个名义未来时域的最小二乘速度，`tprev − t0 < 0`。

`Bpast = ||Hxy|| − ||Dpast_xy − Hxy||`。Bpast>0 表示 D 向过去延拓比零运动更接近历史刚体代理。GT 只用于评分，未进入原图像分数、选点、选相机、模型输入或拟合。

原 2 s 的全部 **1,608,197** 个有效材料点，经同一框几何重建并转 float32 后与既有目标逐点逐分量字节一致；float64 到原 float32 的最大绝对差为 1.9007×10⁻⁶ m。该前向核验不参与 Bpast 的定义。

上一框实际 sample 间隔为 −0.601561 至 −0.399730 s。当前相机相对当前框 sample 时间为 [−0.049308,+0.001615] s，历史相机相对历史框为 [−0.047024,+0.001814] s。本次不插值到相机曝光时刻，所以不能称完美历史对应或实测 scene flow。

## 2. 同一历史有效、图像有效人口上的结果

以下均限定为原未来标签有效、CRN 未覆盖、无同格雷达回波，并有历史标注和原图像分数。每个时域内各对照共享同一基础人口；不同 AUC 目标各自排除恰零收益，另计零值。

|---|---:|---:|---:|---:|---:|
|0.5 s|0.515913|0.496564|0.915396|0.623560|286,717|
|1.0 s|0.516892|0.497417|0.910601|0.613765|279,893|

GT 历史收益是 **oracle reference，不能部署**。四个未来时域复用同一份历史证据，不是四次独立重复。它也不是数学上界：两种收益都包含 D，同一预测幅值及动静组成能贡献关联。

2 s 分组结果仍使用各组相同共同人口：

|未来 GT 组|图像真分数→过去收益 AUC|GT历史收益→未来收益 AUC|速度→未来收益 AUC|共同点数|
|---|---:|---:|---:|---:|
|all|0.516481|0.887170|0.603194|265,599|
|stationary|0.529669|0.792558|0.316884|171,944|
|ambiguous|0.513267|0.661316|0.432033|46,077|
|moving|0.510702|0.970922|0.691259|47,578|

在 moving 组中，历史 reference 的 AUC 为 0.970922，速度对照为 0.691259；图像真分数对过去收益仅 0.510702。因此高历史关联并不只出现在 pooled 动静分离上。七个预定速度区间的 reference AUC 为 0.818、0.931、0.988、0.968、0.977、0.995、1.000；最高区间仅 9 个未来负例点，不能解读为完美判别。以上分组不能消除全部 shared-D 混杂，也不证明因果。

## 3. 支持与损害没有被筛掉

- 2 s 原无雷达、CRN 未覆盖人口：337,615 点；保留的完整对象分母为 10,332，包含 covered、缺历史和缺图像部分。
- 327,355 点有当前／历史框及直接身份链；10,260 点缺历史框；没有链不完整点。
- 历史与图像共同有效：265,599 点，承载该原人口未来负代价的 82.376%。没有把剩余部分填成零或从完整分母删除。
- 原无雷达人口负代价贡献为 0.029417211 m，共同人口贡献为 0.024232650 m；均使用完整对象分母。

在共同人口上，past-negative 组承载 **94.310% 的未来负代价**，也包含 **1.463% 的未来正收益**；moving 子组对应为 95.912% 和 0.798%。这些只是 GT 标签分区的代价构成，不是训练或运行了一个路由模型，也不是模型实际 EPE 降幅。

## 4. 决策与明确下一实验

本结果削弱了“历史运动信息与未来任务完全不相干”的解释，支持先检查观测与材料点的关联。当前被否定的是固定小 patch 匹配的实用判别能力；没有证据支持继续训练该 gate、增加训练时长或增加 seed。O/M0 继续保留。

随后已完成**隔离的 GT 历史姿态图像对照**：保持原材料点、相机选择、真实图像、D／zero 与 broken 对照，增加历史框姿态在实际相机时刻的参考投影。完整 512 样本结果显示修正位置有作用，较高预测速度区间尤其明显；原图像判别仍弱。具体共同支持、缺测账与下一决策见[后续真实结果](history_pose_address_control_train_结果与决策.md)。

该后续对照支持把过去观测对应与 D 的未来轨迹延拓分开检验。官方 RAFT 的指定源码及 Things 权重已取得，下一步是无 GT 的单图像对接口／资源检查；尚无批量光流质量结果。光流不能自动解决内部体素不可见问题，也不能单独证明未来预测正确。

最终方法仍须在不使用 GT 路由的条件下改善 moving 物理误差、控制 stationary 风险，并在原 O 占据任务上提供增益；本轮没有这些新模型结果。
