# 共同运动结论的边界与占据输出读出实验

2026-09-15。只读研究建议；未训练、未读取候选部分成绩、未修改任何冻结源或评价合同。已读 `common_motion_evaluation_reconsideration_v1.md` 的五项来源，本次只新增核实两篇论文及作者代码。

**结论：值得保留一个有界的输出读出实验，但它是新增的、同预算监督诊断，不是找到了 O 原生 flow 的替代算法。先完成当前 O/A/Z 占据与共同变化评价，再决定是否支付缓存和读出训练成本。** 若实施，应把结论写成“在固定读出结构、数据和预算下，候选的占据预测能读出更准确的框刚体代理位移”。它不能消除无身份占据的根本歧义，也不能单独证明候选内部的 motion 分支更准确。

## 现有共同指标能证到哪里

| 实际证据 | 能支持的结论 | 不能支持的结论 |
|---|---|---|
| 原全域五时域 GMO confusion、未来 IoU、FP/FN | 固定任务上未来前景集合更准确；显示保守/激进预测的代价 | 对应关系、速度或轨迹身份更准确 |
| GT 真实速度分组的 TP/FN/recall，加全域一次计数的 FP | 哪类端点运动对象的未来占据漏失减少；未知/重叠和低速代价可见 | moving recall 提高本身证明运动改善；不能将所有 FP 分别重复归入各运动组 |
| 两端 GT 共同有效域上的 `00/01/10/11` confusion | 新增位置、腾空位置和残影的预测是否改善；静止复制不能靠缺少匹配对象免罚 | 变化必由物理运动产生；遮挡/稀疏标注变化同样会改变状态 |
| 新增同预算输出读出器的代理 EPE | 占据序列对指定运动标签的可预测性，以及扩展系统 `模型+读出器` 的误差 | 原 O 有 native flow；物理逐点 scene flow、实例身份或内部机制得到唯一验证 |

这里 `0` 是非 GMO，包含其他类别和空域，不能把 `10` 一律解释为物理空间完全腾空。低端点速度也不等于物理静止。两个相同物体交换身份可产生完全相同的五帧占据；任何只读这些输出的确定性读出器都不能一般性恢复其身份对应。加入运动监督能学习数据先验，不能逆转这种不可识别性。

## 新核实的一手依据

**MotionNet，Wu、Chen、Metaxas，CVPR 2020。** §3.1–3.4（论文 PDF 第3–4页）将历史 LiDAR 对齐至当前坐标，体素编码为二值、以高度作 BEV 通道，学习稠密二维位移。作者代码确有五帧二值输入与位移头；标签来自框对应。它支持“无需先做实例组件匹配即可监督学习稠密位移”的可行性，不证明我们的预测 GMO 足够。其三头模型、历史输入、二维标签、推理静止抑制与 ROI 评分均不同，不移植其评价规则或宣称复现官方成绩。[正文](https://arxiv.org/pdf/2003.06754)、[二值输入 L123–132](https://github.com/merlresearch/MotionNet/blob/aea30a1777f06e83f65fa4cb3e93ae95519d9a5b/data/nuscenes_dataloader.py#L123-L132)、[forward L194–220](https://github.com/merlresearch/MotionNet/blob/aea30a1777f06e83f65fa4cb3e93ae95519d9a5b/model.py#L194-L220)、[标签与有效域 L462–515](https://github.com/merlresearch/MotionNet/blob/aea30a1777f06e83f65fa4cb3e93ae95519d9a5b/data/data_utils.py#L462-L515)。

**Hewitt、Liang，Designing and Interpreting Probes with Control Tasks，EMNLP 2019。** §2–3（PDF 第3–6页）区分表征提供的信息与探针学习/记忆任务的能力，以随机词类型控制任务检验选择性；同等任务分数可对应不同选择性。作者代码公开控制任务和不同容量的线性/MLP 探针。该结果来自 NLP，不为运动探针提供统计保证；其启发是必须说明读出器和先验的贡献。[正文](https://aclanthology.org/D19-1275.pdf)、[作者控制实验入口](https://github.com/john-hewitt/control-tasks/blob/be70d7f42324797dcf2bb5360a94d8e64100fea8/README.md#L47-L53)、[线性/MLP 实现 L366–451](https://github.com/john-hewitt/control-tasks/blob/be70d7f42324797dcf2bb5360a94d8e64100fea8/control-tasks/probe.py#L366-L451)。

**未找到并核实一个可直接用于“冻结模型的五帧预测 binary GMO → 框派生 EPE”的公认官方协议。** 以下为本项目提案，不是文献既定指标。MotionNet 作者仓库为 AGPL-3.0-or-later，内置 nuScenes 派生代码另有 CC-BY-NC-SA-4.0 标注；本建议仅借鉴输入表示和稠密读出原则，不复制其旧依赖、标签或筛选逻辑。精确版本及文件 SHA 见同名 `_sources.json`。

## 一个优先方案：相同预算的稠密输出读出

1. **只读输入。** 冻结最终 O/A/Z；每个 anchor 只用原 evaluator 插值→argmax 后的五帧 binary GMO，空间固定 t0 LiDAR R。不得读取 latent、原生 motion、雷达、框中心/大小/类别/ID、GT mask、真实未来位姿或轨迹作为读出输入。名义时域顺序固定。先产生整个空间的位移场，再用 GT 独立选点评分，不给网络 GT 框裁剪或对象查询。
2. **固定表示与容量。** 可先采用完全相同的 `4×4×4` 块前景计数，将 `512×512×40` 转为 `128×128×10`；除以64后作为五帧、50个高度/时域通道。这是硬输出的占据比例，不是模型概率。用一个小型多尺度二维 U-Net，输出 `4×3×10` 通道米制位移；其上下文必须覆盖大位移，不能用仅几格感受野的两层卷积把高速运动人为判负。通过固定几何插值在已有 `200×200×16` 源格点评分；不投影掉 z、不重新划分标签。网络宽度/层数、计数表示及插值在 train-only 工程预检后冻结，不按 dev 选。该下采样会丢失亚块信息，因此负结果只约束这类读出，不能证明完整输出无运动信息。
3. **标签和分母。** 复用 `sparse_motion_v1`：t0 唯一框归属点、四时域真实 SE(3) 框材料点位移、future-valid mask，单位米。所有共同有效监督点均计分，即使 O/A/Z 都没有预测出该物体；未来点出 ROI 仍保留。不把虚拟框内点叫实测 scene flow。缺未来框不填零；t0 不存在的新生没有源点位移，其占据召回仍由共同指标单列。框内无唯一点、重叠和缺帧的计数不得消失。
4. **同训练预算。** O/A/Z 各自一个同结构读出器，**初始 state 字节相同，最终权重分别学习**；“同参数”指相同参数化、初始化和超参数，不是要求最终权重相同。沿固定 train512/256 scenes，seed11、同样本顺序、acc4、同损失/优化器/LR、4 passes/512 updates；原模型全程冻结。可复用已审 source-motion 的物体内平均、组平衡 Smooth-L1 口径，但不能用模型各自预测成功的点作 loss/eval mask。每臂只取固定最终状态。readout 的 dev200 不参与容量、阈值、步数或模型选择；原开发集已暴露，依旧不是新盲测。
5. **只增加一份关键训练控制。** 因 O/A/Z 的 t0 必须相同，可共用一份 `R_t0`：输入五个位置都复制相同 t0，标签、容量、初态和512更新预算同上。它控制从当前形状/道路分布学习运动先验的能力。`R_A/R_Z/R_O` 比它好，才给出超出该固定 t0 读出的未来序列证据。这是我们针对场景的控制，不照搬 NLP 随机词标签为“标准 selectivity”。对已训练读出器打乱时域可作廉价敏感性记录，但存在输入分布变化，不能替代这个训练控制。

建议主读出分数预先定义为：每对象先平均其有效材料点 XY EPE，按四个未来时域等权，再比较相同 GT 支持上的候选−O、候选−Z；四时域各自的 all/低速/过渡/较快/高速、3D EPE、median/p90全部保留。场景配对 bootstrap 仍用10,000次/seed11；必须明确选择“对象加权点估计”还是“场景等权点估计”，不得将一个口径的区间贴给另一个。单训练 seed 的区间只反映所选场景抽样，不覆盖读出训练随机性。具体主分组和实质误差阈值若要用于晋级，应在 dev 读出结果前冻结，不能把显著性自动当实用改进。

## 成本、先行判断与停止规则

当前日志中的 confusion 不能重建 binary 输出，除非已有逐体素资产，否则需一次新的固定模型缓存提取。O/A/Z 共用冻结 O 前向，理论上每 anchor 只需一次 O 推理再算两门控；实际 producer 必须验证，不能按三套独立完整模型估时。仅计未压缩数据：712 anchors×3 models 的五帧 bit-pack 约 **13.04 GiB**；上述每块 `uint8` 计数约 **1.63 GiB**，每次 float32 读出输入约3.125 MiB。后者不包含原输出供核验的存储。

完整提案是3个模型读出器加1个共享 t0 控制，共2,048次 optimizer 更新、8,192个训练 anchor 呈现，随后4×dev200；不是多训练 seed。只有真实 profile 才能给墙钟与显存预算，不能挪用先前 BEV motion-head 的203秒估计。先用既定训练样本做有限加载/梯度/成本预检，丢弃预检权重；本文件没有授权或执行这些任务。

- **优先实施的情形：** 当前 A 在原占据/变化上有继续研究的信号，但“运动是否真正更准”仍决定下一阶段；共同标签支持完整且小读出能实际学习。它比组件质心覆盖不足的 EPE 更可辩护。
- **若 candidate EPE 比 O 与 Z 好，且优于共享 t0 控制：** 可以报告同预算下更好的运动可解码性，并联合原 IoU/FPFN说明扩展系统结果；A−Z 支持当前连接在该读出任务上的价值，仍不是唯一因果归因。
- **若只优于零位移，却不优于 `R_t0`：** 不足以证明未来占据提供了额外运动信息。若静止组变差或中位数恶化，必须保留，不能只选择 moving mean。
- **若读出全面失败、明显欠拟合或 A≈Z≈O：** 只否定当前表示/读出/预算下的主张；不凭此断言原占据信息不存在，也不立即扩容量、多种子或调 dev 阈值。先依据训练损失、源覆盖和共同占据结果决定停止该附加路线。

即使探针结果为正，论文也不能把“监督训练的输出解码器”写成不需要额外训练的通用运动指标，不能将它的 EPE 放在 O 的 native-flow 栏，更不能把模块组合或四状态计数包装为 ICLR 新颖性。是否达成“超过 O 且运动更准”，仍需在明确采用上述扩展系统定义后，综合真实占据、共同读出及控制结果判断；当前目标未完成。
