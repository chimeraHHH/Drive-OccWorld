# 16 个训练 anchor 的真实运动 oracle：结果与下一步决策

**结果支持“正确运动能给 O 提供互补信息”，但不支持用纯传播替换 O，更不是新模型超过 O 的证据。** 固定 0.5 log-odds 融合得到 22.1499%，高于原 O 的 21.4686%；只传播 O 当前预测，即使使用真实未来 box 运动，也只有 19.6463%。原 O 和任务坐标／fine GT／评价器保持不变。下一步适合训练只依赖观测状态的运动预测头，再检验运动精度和完整占据输出；oracle 本身不得进入候选模型或目标完成声明。

half-oracle 相对 O 的四时域 IoU 分别提高 **0.4533、0.4630、0.6258、1.1829 pp**。未来 pooled FP **增加 14,470**，FN **减少 13,651**：它不是单纯“减少前景、变得保守”的提升，也不是所有错误均下降。具体 ΔFP 为 `[-12749,-2732,+9171,+20780]`，ΔFN 为 `[+880,-1314,-4439,-8778]`；早期和后期取舍不同。纯 oracle 的 FP 比 O 多 **187,699**，FN 少 **6,552**，仍不足以提高 IoU。

half-oracle 比相同形式的 half-static 高 **4.2117 pp**，说明这一路径中正确的运动比静态复用有价值；不能由此推导任意融合都有效。按每个 scene 自己的两 anchor 汇总，half-oracle 相对 O 有 **6/8 scene 为正**，最差 −0.8104 pp、最好 +3.4793 pp，仅作异质性描述，未新增显著性检验或置信区间。

已将记录内每个对象的 `source_voxels`、oracle 有效源点数、重叠数，与独立生成的真实 `sparse_motion_v1` 前 16 标签核对，全部精确；CV 支持数按有历史的对象重新相加一致。另从原 raw labels 核对了 **1,694 个对象×未来帧**的中心位移、实际 dt 和 global xy 端点平均速度。future 有效性不必单调：原始对象可能某帧缺失后再次有标注，未插值补齐。

源概率质量每个时域合计 27,893.0003。上述质量统计是从已认证记录独立求和，未重新计算／读取未保存的完整概率张量。注释支持点只占全网格约 0.4%，但承载约 64% 的源前景概率，说明不能以网格占比很低判定运动监督没有信息。未覆盖与未来缺失的源采用零位移继续存在，未被删除；重叠 box 不任意归属。这里的有效支持也包含低运动对象，不应全称为动态点。

CV 的支持来自历史可用性，每个时域均为 40,490 点、覆盖 64.4502% 的源质量；oracle 的支持依赖该未来帧是否有标注。因此 oracle−CV 不能全部归因为速度误差，二者还不同于支持集合及是否包含刚体旋转。当前 probe 的 `moving` 标记使用 `>=0.5`，新稀疏标签的高运动组使用 `>0.5`；这 1,694 个实际记录中没有速度恰等于 0.5 的记录，而且 probe 的该标记没有进入本表七条件评价。

边界丢失率约 0.24–0.40% 只描述累计源质量，不能据此断言边界误差对 IoU 无关。传播使用未归一化三线性前向累加，碰撞可使值超过 1；之后 clip 到 `[1e−6,1−1e−6]` 再转 logit。这不是经过校准的占据概率并集。记录里低值截断体素很多，也不能按其数量认定它是主误差来源。

**零位移传输的质量完全守恒、碰撞 excess 为 0，但 static_splat_O0 与直接 persist_O0 的评价仍相差 −0.1218 pp。** 两者经过的概率／logit处理不同；源码先 softmax、clip、转 logit，而原 fine evaluator 在 argmax 前对 logits 做三线性上采样，故零位移不保证整个数值处理链的 fine-resolution 评价恒等。这是需要披露的处理差异，不是数据证明几何 transport 实现错误。oracle 与 static_splat／两个 half-blend 的处理链相配，是更合适的运动对照。

## 可执行的下一步与否定边界

1. 保留 O，继续已授权的观测状态→稀疏刚体点位移预训练。GT 当前／未来 box 只用于损失和独立评价，不得在部署时提供 source assignment、oracle flow 或真值速度组。先完成真实小预算前向／反向／资源预检，再按冻结单 seed11 方案正式训练。
2. 运动评价同时报告低运动、过渡和较高运动组的对象等权误差、相同支持的零运动基线及有效数量。标签中大量低运动对象使总平均不足以判断运动是否更准确；历史 GT CV 只能作为特权诊断参照，不能伪装为模型输入可用的 baseline。
3. 运动代理误差下降不等于占据预测超过 O。当前点监督没有约束 box 外所有网格的位移；后续实际传播必须完全依靠模型可用信息，检查其完整输出和 FP/FN，不能推理时借真值 box 限定安全区域。是否超过 O，仍要在同样本、相同 fine GT／指标下评价真实 learned candidate。

这次 oracle 是“给定真实未来 box 时，这个具体源和算子是否存在改进空间”的特权探针；**不是所有方法性能的数学上界**。纯 oracle 低于 O 不否定所有运动建模，而融合的小样本正结果也不保证学得运动后仍有收益，更不构成 ICLR 新颖性或泛化证据。当前合理决策是推进有监督、可被否定的运动学习阶段，不宣布目标完成。
