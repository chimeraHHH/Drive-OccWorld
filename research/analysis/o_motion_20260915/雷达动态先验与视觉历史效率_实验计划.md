# 用雷达动态先验减少视觉历史：后续实验计划

记录日期：2026-09-17。来源：用户本轮提出的研究方向。优先级：高；状态：**待验证假设，尚未成为论文实验结论**。不替代当前“超过 O 且运动更准确”的目标，作为潜在贡献与正式评价维度加入后续 roadmap。

## 科学命题

视觉历史提供对应关系、位移和遮挡信息；Doppler 则直接约束径向相对速度。在语义、空间几何和 ego-motion 支持下，雷达动态观测可能减少未来世界建模对视觉历史的需求，在较少相机历史或更小时间编码预算下保留预测质量。

目标不是只证明“加雷达有收益”，而是验证一个可量化的替代关系：

`短视觉历史 + 雷达 Doppler` 能否达到 `较长视觉历史、camera-only` 的预测质量，并在真实计算预算下更省。

单次 Doppler 不能独立恢复完整三维物体速度、身份、行为意图或遮挡区域。camera-only 单帧也可能利用外观先验预测运动，不能将其说成没有动态理解能力。

可用于后续英文写作的假设表述（实验完成前使用 investigate，而不写 achieve）：

> Doppler measurements provide a direct constraint on radial motion, complementing motion inferred from visual history. We investigate whether radar-informed dynamics can reduce the visual history and temporal computation required for accurate future occupancy prediction.

## 必须先审计的输入和成本

1. 将 H 定义为含当前时刻在内的真实相机时间点数，同时记录每点相机视角数、最早/最晚 sensor timestamp、采样间隔和历史跨度。BEV memory slot、cached feature、输入 RGB 帧数分别统计。“一槽 BEV”不等于“一帧相机”，当前已含时序压缩的缓存不能直接充当 camera-H=1 对照。
2. 所有窗口截至同一个 t0，当前帧及当前视角完全相同。改变 H 时同时区分“相同采样间隔、不同跨度”和“相同跨度、不同采样密度”，首轮只锁定其中一种，不能混淆。
3. 雷达 sweep 数、时间跨度、传感器数和预处理固定并公开。主 Doppler 替代实验优先采用每部雷达最近一份合法观测，另报告多 sweep 情形；不能把更长雷达历史算成免费瞬时动力学。
4. 分开测 cold-start/windowed 推理与正常 streaming 推理。在复用历史图像特征的实现中，每个新时刻可能只编码一次当前图像，减少 H 不会按比例减少 image-backbone 成本；必须实测 temporal fusion、缓存显存、启动成本和端到端延迟。
5. 不用已缓存 BEV 的本轮诊断用时，作为 camera/radar 端到端速度证据。同步 CUDA、固定 batch/分辨率/精度/设备，记录预处理、相机编码、雷达编码、时间融合、future rollout 及总延迟，报告 steady-state median/p95、峰值显存与算子覆盖明确的 FLOPs。共享 GPU 的调试耗时不直接作为正式速度结论。

## 对照矩阵与分阶段资源安排

候选 H∈{1,2,3,4,8}，以真实数据和实现支持为准，正式跑前冻结确切集合。源码审计确认当前原生输入为 H=3，故首轮先考虑 H=1 与 H=3 两个端点，证据支持后补其余点。沿用单 seed11，不堆多种子。比较共享 backbone、分辨率、预训练、监督、场景、未来 horizon 和解码器的**自有实现**；第三方官方 baseline 仍只测官方权重，不新增其重训任务。

| 条件 | 要回答的问题 |
|---|---|
| camera-only，逐个 H | 视觉历史增加带来的质量与成本曲线 |
| camera + radar，逐个 H | 雷达是否将质量—成本曲线整体改善，尤其短历史 |
| 同 H、同雷达几何/RCS/点数，去除 Doppler | 收益来自直接动态证据，还是仅来自几何和可见性 |
| 同一模型中置零/打乱 Doppler，作诊断 | 模型是否使用对应的速度信息；该干预不能代替训练对照 |
| camera-only 的等实际计算预算配置 | 排除多模态额外容量/计算带来的普通收益 |

删除 Doppler 要覆盖 raw/compensated velocity、speed/heading 等派生通道以及使用 Doppler 的预处理路径；仅在已用速度完成运动补偿之后把速度通道置零，仍可能残留动态信息。保留雷达位置和 RCS 的设计也要明确它与完整管线消融的区别。

历史长度研究必须重新取得相应合法观测特征；冻结编码器和训练编码器属于不同实验设置，分别报告。匹配训练样本和更新次数的对照与匹配训练计算量的对照分别解释，不声称二者同时严格相等。

## 指标、图表与成败判据

主图为未来预测质量—端到端延迟的曲线，不只绘制质量—帧数。附图包括质量—FLOPs/显存、每个未来 horizon、moving/stationary 和径向/切向运动分组。现有 GMO 是二分类 movable occupancy IoU，不是语义 mIoU。

主评价维持原全域 future GMO，另外检查 moving recall、静止误运动、认证后的物理 EPE及共同输出的运动相关评价。不能只靠减少前景预测或只取成功检测对象获得“同等性能”。雷达覆盖/距离、径向速度可观测性、遮挡程度的分组保留原分母；不靠筛掉切向运动或无雷达支持样本隐藏限制。

正式实验前冻结“相当性能”的非劣界限、实际速度提升门槛和独立确认场景；现在未冻结数值门槛，不能事后用结果倒推。单 seed 下可做场景配对 bootstrap 来描述样本变动范围，但不能将其声称为训练随机性的置信区间。

支持贡献需要同时满足：短历史 C+R 达到预定质量标准；相比长历史 C 的真实系统成本下降；Doppler 训练消融支持动态信息起作用；收益通过运动相关指标而非纯静态/误报变化解释；在未用于选路线的场景复核。若只有同 H 加雷达增益，则只支持融合收益；若只有冷启动变快而 streaming 不变，则限定为启动/窗口成本；若只有高径向可观测子集有效，则限定物理适用范围。

## 贡献主线与可辨识的机制证据

用户提出的重点是减少视觉历史的需求。后续论文应围绕“为估计运动而付出的时间观测与计算代价，能否由直接动态观测部分替代”组织，而不把单次融合增益当作该命题的证明。视觉历史仍承担身份对应、遮挡恢复、切向运动和行为变化的估计，不能被概括为只用于速度。

除短历史完整模型与长历史纯视觉的主比较外，记录同 H 的 Doppler 增益 `D(H)=Q(C+R_geometry+Doppler,H)-Q(C+R_geometry,H)`。比较短/长 H 的 D(H)，检查 Doppler 是否更能补偿缺少视觉运动证据的情形；这种交互可支持机制解释，但不单独证明成本下降，也不作为事后删选结果的条件。所有差异采用同一评价人口和同一质量指标。

首轮各 H 使用匹配训练设置；另做的测试时截短历史属于输入干预，不能与已适配短历史的模型混在一条主曲线上。H=1 指一个时刻的完整多视角相机输入，不是只保留一张视图。对于当前窗口重算实现，从 H=3 到 H=1 减少的是两个时刻的图像编码；是否带来净系统收益仍需将雷达分支和全部时序/预测开销计入。最终优先报告保持未来动态质量所需的历史长度与真实成本，而不是只报告帧数。
