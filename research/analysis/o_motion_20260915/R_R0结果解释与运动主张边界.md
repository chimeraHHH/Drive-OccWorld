# R／R0 结果解释与运动主张边界

2026-09-16，结果揭晓前的科学解释备忘；未读取任何 R／R0 性能结果，不修改冻结协议、指标、阈值或晋级门。

**本轮最多证明“运动信息的连接改善了未来占据预测”；不能证明物理位移更准。** R 和 R0 都冻结同一 D，位移预测器没有改变；O 本身没有同语义的原生 flow，不能给 O 虚构 EPE。开发 200 anchors 的改善仍是开发证据，“原任务超过 O”的完整验证要在相同 5119 anchors／150 scenes 上成立。

原 GMO 评价全部有效体素，moving recall 则将未来 GT 正体素唯一归属到未来真实框，再按该实例从 t0 到 h 的 global-XY 中心端点距离／真实 dt 分组。`>0.5 m/s` 是 GT 分组，不是模型识别出的运动状态；它不测预测实例身份、位移方向、速度或米制位置误差。全局 FP 只计一次，不能冒充 moving precision。四状态 01／10 是固定位置占据变化，也不等于实例运动轨迹。

## 解释矩阵

下表的“改善”应同时报告点估计、既定统计口径的配对不确定性和逐时域结果；区间跨零表示增量尚未辨明，不表示等效。这里只解释结果，不增设每时域均不下降、0.5 pp 或其他新成功门。

| 实际结果关系 | 可支持的结论 | 仍不能推出 |
|---|---|---|
| R 比 O 的 GMO 与 moving recall 都好，并且 R 比 R0 也有同向增量 | 这个同容量预测器中，D 位移连接有助于未来占据与真实运动目标覆盖；需完整披露 FP/FN 的代价 | D 的物理 EPE 改善，或特征搬运普遍优于概率搬运 |
| R、R0 都比 O 好，R−R0 未辨明或为负 | 新的稠密上下文／残差预测器有效；尚无额外运动连接收益 | 运动机制已被验证，或 R 与 R0 已证等效 |
| R 比 R0 好，但仍不及 O | 连接在新预测器内有用，却未达到用户要求的更强原任务模型 | 用内部对照胜出替代超过 O |
| GMO 提高、moving recall 下降 | 整体占据交并比收益伴随运动目标漏检代价，与此前 A/J/D 的风险相似 | “运动预测更准确” |
| moving recall 提高，GMO 不增或下降，FP 增多 | 运动目标覆盖改善，但可能来自预测扩张；属于待解释的覆盖／误报权衡 | 综合更好，或正确位置对应更准确 |
| 两项都未改善 | 当前有限训练与固定连接未给出收益 | 物理运动无用、所有特征传输无效，或继续盲目加预算必能解决 |

## 怎样解释“召回增加”

只有 moving recall 增加不够：将大片区域预测为前景也能覆盖目标。原 GMO、全部 FP/FN 与 01／10 统计可约束这种解释；若 GMO 与 moving recall 同升且全局 FP 不增，证据更强，可准确说“更少漏掉真实运动目标的未来占据，同时全局误报未增加”。但即便如此，误报也可能在不同对象／区域间重新分配；全局 FP 无法提供动态目标专属精度，更不能恢复对象对应。若 FP 上升，应量化代价，不把任何上升自动判为失败，也不由总 IoU 掩盖它。

R−R0 是**让此训练系统使用 D 位移而非零位移的增量**。位移同时改变运输特征的目的位置、支撑 W 和其后学习过程；它不是在固定其余中间量下仅改变“物理正确性”的试验。正结果不能唯一归因于准确的物体对应，也不能分离载体、空间支撑和后续适应。t0 逐位保留避免本轮当前帧代价，但不构成未来运动准确性的额外证据。

## 何时需要更直接的位置误差

若要将表述升级为“预测了更准确的动态未来位置／轨迹”，或者覆盖收益仍无法排除扩张、合并目标及身份错配，就需要另行定义公平的空间误差／对应评价：所有模型同一输出读出、同一物理坐标与时域，并同时处理漏检和伪目标，不能只在成功匹配或已有预测支持的对象上算距离。O 没有实例 flow，当前稀疏二值占据也不能直接当框中心或 EPE；GT 裁框后取预测中心会带入正确目标位置。若采用同类学习读出，它衡量的是输出可解码的运动信息，不是原模型的原生 flow。此项属于后续主张所需证据，**不是本轮新增指标或启动授权**。

此前 train16／8 scenes 的部分真值位移替换相对 D 带来 GMO +0.234675 pp、moving recall +0.858721 pp，说明已有合法源上的位移仍有作用；它既不是完整 flow 上界，也没有预言 R 必然成功。约 40% 的有效运动 anchor-instance 在唯一虚拟源点中无 O hard-positive，不能等同完整物体不可见率。新稠密残差可在 W=0 处修改输出，因此旧局部传输的影响域不能直接套到 R。单 seed、历史开发集暴露、体素加权偏重较大目标以及不同 h 的速度分组成员变化均须保留披露。
