# 二值占据输出能否公平评价运动：两项可实施选择

2026-09-16。只读研究备忘，核对三篇原论文及作者代码；未改变 R/R0 指标、协议或晋级标准，未生成模型成绩。

**不存在从五帧无身份 binary GMO 一般性恢复真实物理运动的唯一解。** 同形物体在相邻采样帧间交换身份，或对称物体发生不改变占据的旋转，都可能给出相同占据序列和不同材料点位移。这是本项目的可识别性推理：任何只依赖这些输出的确定性评分都会相同，换 Chamfer、GOSPA 或训练读出器都不能消除该歧义。

## 三项一手核证

- **Occupancy Flow Fields，RA-L 2022。** §III-C、§IV-C（PDF 第3、5页）分别定义额外 backward flow、占据指标、EPE 和联合 flow-traced 指标；后两类并非只需占据。官方 `_compute_flow_epe` 还按非零 GT flow 计分，不能照搬为包含静止对象的完整评价；所核 `_flow_warp` 当前停用。[论文](https://arxiv.org/pdf/2203.03875)、[官方代码 L203–309](https://github.com/waymo-research/waymo-open-dataset/blob/99a4cb3ff07e2fe06c2ce73da001f850f628e45a/src/waymo_open_dataset/utils/occupancy_flow_metrics.py#L203-L309)。
- **Point Cloud Forecasting as a Proxy for 4D Occupancy Forecasting，CVPR 2023。** §4、式(16–17)评价几何点集距离，射线指标则依赖传感器射线；它们没有材料点身份对应。官方 near-field Chamfer 在任一裁剪后点集为空时返回零，不能继承这一空预测漏洞。[论文](https://arxiv.org/pdf/2302.13130)、[作者代码 L17–67](https://github.com/tarashakhurana/4d-occ-forecasting/blob/e1ea9434113d303986684395a961aaacac90d470/cvpr23-evalkit/evaluate.py#L17-L67)。本项目的 0 类含非 GMO，不能拿 GMO 首命中当真实 LiDAR 第一回波。
- **GOSPA，FUSION 2017。** §II-B、命题1（PDF 第2–3页）在 α=2 时把总代价分解为匹配位置误差，以及每个未匹配真实／预测目标的 `c^p/2` 代价；作者实现保留空集合的漏检／伪目标成本。[论文](https://arxiv.org/pdf/1601.05585)、[作者 GOSPA.m L56–131](https://github.com/abusajana/GOSPA/blob/fe0fe088a1d961a5e3986e611d224781736fa80b/GOSPA.m#L56-L131)。它需要两边同语义的有限目标集合；把框中心和稀疏组件质心相配，或把体素数量当物体数，不会自动获得有效的对象评价。

## 选择一：已有稠密输出读出器，作为运动信息诊断（优先用于位移问题）

冻结 O、R、R0，各自只输入同格式的五帧预测 binary GMO。已有 `occupancy_motion_readout_v1.py` 的 923,576 参数模型及八项真实 CPU 合同测试已通过，**尚无读出训练或预测能力证据**。若另外授权实施，应同结构、初态、seed11、训练样本顺序／步数／损失和固定最终状态，分别训练读出器；不读模型 latent、内部 D、雷达或 GT 框作为输入。全空间输出四时域米制位移后，再用共同 `sparse_motion_v1` 的 GT source indices 和 valid mask 评分，不先 GT 裁框、取质心或匹配预测组件。

所有标签有效对象／源点都进入分母，包括模型完全未预测到的对象；缺未来标签、无唯一材料点等不可评支持必须计数，不能算零误差。按既定物体内平均和运动分组比较同支持 EPE：`||(p+δ_hat)−(p+δ_GT)||`。这是虚拟框刚体材料点的未来位置误差，不是实测 scene flow。可共用一个同预算的 t0-only 读出控制，区分未来输出所含信息和训练先验；它属于该后续诊断设计，不是当前 R 的新增训练臂。

**必须与原全域 FP/FN、GMO 和共同漏检统计一同解释。** 稠密读出没有“只对检测成功对象评分”的漏洞，但 EPE 本身不处罚占据伪目标，也可能用先验补出被占据模型漏掉的对象。因此其单独改善不满足“不忽略伪目标／漏检”的整体目标；不得把背景无物理对应处人为标零 flow 来伪造该惩罚。它最多支持“同等读出预算下，预测占据序列可读出的刚体代理运动更准确”，不能给 O 声称 native flow，也不能把 R 冻结的 D 写成 EPE 改善。成本是新的输出提取／计数缓存、读出训练及评价，八项测试不提供耗时或成功保证。

## 选择二：全域双向位置距离账目，补充现有 IoU／计数（无需学习）

在原 h 时域 GT 有效域内，将所有预测正体素中心组成 P、所有 GT 正体素中心组成 G，坐标统一米制 t0 LiDAR。对每个 G 点计算到**完整 P** 的最近距离，对每个 P 点计算到**完整 G** 的最近距离；不做框裁剪、组件提取、预测成功过滤或新阈值分割。GT→P 的结果可按现有 GT 运动组报告，P→G 只能全局报告，因为伪目标没有真实运动身份。保留原完整 TP/FP/FN、两边点数与距离均值／尾部统计，不能只交一个 Chamfer 平均值。

若实施，空集必须事先显式定义：某边为空且另一边非空时，所有另一边点仍保留为未覆盖／多余，记录其完整数量；距离用固定 ROI 对角线这一几何上界记账并标明约定，不返回零、不跳过样本。两边均空则无位置支持、误报漏报数零。最近邻查询可用 CPU 空间树逐帧计算，不需要巨大两两代价矩阵；已有 confusion 无法重建位置，需要重新取得逐体素输出，成本不可误写为只分析 JSON。

这是一份**本项目拟议的几何诊断，不是复现官方 Chamfer 或 GOSPA**。最近邻允许多个点借用同一预测，并受形状、密度和附近其他对象影响；完整 FP/FN 必须补充其缺少基数惩罚的弱点。它能区分“漏掉的未来占据距预测很近还是很远”，不能测身份一致性、速度或材料点位移。若要求真正逐对象漏检／伪目标加定位的 GOSPA，则必须先有可信的、完全由输出生成的对象预测器；我们组件代理的两端完整纯覆盖仅 0.70%–2.29%，此入口尚不成立，本备忘不再推动该代理。

**建议选择的依据：** 要回答物理代理位移可读性，优先考虑选择一；只需解释 moving recall/GMO 的位置误差形态，选择二更直接。两者均不替代既有全域任务评价，也不能让 R/R0 在 D 冻结时宣称内部物理运动改善。若用户要求原模型本身输出更准确的真实运动，就仍需可比较的显式运动输出／对应标签；不能靠一个输出几何评分补造这一能力。
