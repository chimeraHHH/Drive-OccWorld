# 历史图像对应诊断：真实结果与研究决策

**结论：当前 7×7 ZNCC 对应分数没有提供足够的运动收益判别力，不进入门控训练。O/M0 保持冻结。** 这是否定一套具体观测检验，不能据此否定视觉运动信息。

本轮实际完成 train512 / 256 场景、6,144 张原始当前／上一关键帧图像、1,740,053 个原始材料点的 CPU 提取。图像计算耗时 125.225 秒，模型前向与优化器更新均为零。传输超时后恢复文件传输，未重跑计算。所有 512 个结果文件及端点元数据完成 SHA/长度核对。

## 1. 比较的是什么

保留 D 四个未来时域的名义最小二乘速度，将它向过去延拓，与零世界运动假设比较。两种假设均使用各相机真实时间、内外参与 ego pose，同时补偿当前和过去两端。按 current-zero 的几何光轴距离一次选相机；不根据图像得分、D 或 GT 选择视角。

分数为 `s = ZNCC(D-current, D-past) − ZNCC(zero-current, zero-past)`，正方向在分析前固定。对照仅把过去图像水平循环移位半个图宽。真实分数、错误对应及速度对照使用完全同一有效点；低纹理、越界等缺测仍计入完整物理分母。

AUC 的正例是同一点 D 的未来 XY 位移误差小于零位移的误差，负例相反。它衡量收益排序，**不是 future IoU，不是 EPE 改善，也不是部署泛化验证**。点权重为原对象点数的倒数；完整物理贡献仍除以全部原有效对象数。原 D 已见过这些训练场景。

## 4. 研究解释与下一步

当前证据支持停止“直接把原图小 patch 相似度变成门控”的实现。它尚未定位下面两种机制各占多大作用：

1. **时间连接问题。** 当前分数检查的是把未来 D 平均速度延拓到过去，评分目标却是未来轨迹收益；转弯、加减速会使两者不一致。即使过去对应完美，也不保证未来位移正确。
2. **观测对应问题。** 当前 source 是 GT 框内部的虚拟刚体材料点，不是测得的可见表面点。能投影且有纹理，不等于图像像素属于同一材料表面；遮挡、透视尺度和重复纹理均可能使真实运动的 patch 得分差。

下一项已进入实现的是 **CPU 历史运动与未来收益连接诊断**：用已有原始 GT 框的当前／上一关键帧姿态，重建同材料点的真实历史位移；GT 仅用于诊断评分。比较 ZNCC 对“过去运动收益”的排序，以及历史收益这个 oracle reference 对“未来收益”的排序。缺历史标注单独记账，保留未来完整分母和原速度区间。它使用关键帧时间，尚不消除相机与关键帧约数十毫秒的异步差异；不称物理测量真值或数学上界。**后续 CPU 诊断现已完成，见[历史运动—未来收益结果](history_motion_alignment_train_结果与决策.md)：共同人口上历史 reference→未来 AUC 为 0.887170，但图像分数→过去 AUC 为 0.516481。GT reference 不是部署成绩。**

若历史收益本身无法预测未来收益，应先修正过去证据与未来动力学的连接；若历史收益有判别力而 ZNCC 对历史收益仍弱，应先解决可见表面对应／特征表达。若采用官方 RAFT 权重，也只做冻结推理；光流不能自动解决体积内部点的可见性或未来因果问题。不会因为新模块易于接入就再次启动短训。

本轮没有新占据结果，没有超过 O 的结论。有效候选仍须同时验证原任务占据、moving 物理误差和 stationary 风险，再决定是否进行原 full5119 验证。
