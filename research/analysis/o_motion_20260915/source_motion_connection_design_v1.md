# 学习位移接入 O：一页待冻结提案

**优先检验“观测得到的源支撑＋运动传播能否补充 O”，先冻结 O 和预训 motion，只训练融合。** Oracle16 的 half 融合 +0.6813 pp、纯传播 −1.8223 pp 支持互补假说；16 train／8 scene 的特权结果不保证 learned candidate 有效。本文件不改现行协议，不授权启动。

**源与补全契约。** 在固定 t0 LiDAR R、原 200×200×16 XYZ 网格，取冻结 O 的当前预测概率 `p0`，以其原二分类 argmax 前景 `m0` 为输入可得的源支撑；不读 GT box、GT有效性、未来速度组或未来图像。令 `S_h=splat(m0·p0,d_h)`、`W_h=splat(m0,d_h)`，只保留算子原有的界外权重丢弃和碰撞累计。`m0` 不等于可靠运动区域：O 的误报及 box 外未监督位移仍是实际风险。此限制区别于原 oracle 对整个稠密 p0 的运输，不能沿用 oracle 分数当预期收益。

用共享小型逐体素门 `g_h=σ(MLP[ℓO_h,logit(clip(S_h)),log(1+W_h),h])`；建议 4→16→1、末层零初始化使初始门为 0.5，两臂完全相同。当 `W_h>0`，输出 `ℓ_h=(1−g_h)ℓO_h+g_h logit(clip(S_h))`；否则严格输出 O。t0 原样保留，仍用原完整 GT、上采样、argmax。门不直接读取位移向量或特权信息。O 分支始终存在，未覆盖区域的出生／遮挡补全交回 O；在错误运输覆盖区域并无“新生必受保护”的保证，须报告相关漏检。概率质量相加不是概率并集，固定 clip 和所有数值处理两臂一致。

**主比较。** A 接预测位移；Z 使用同一预训 motion checkpoint，但将传输入口位移置零，两者拥有相同 O、motion、门、初始化、训练样本顺序、优化更新和原 O 占据损失。预测 source mask 全部相同；Z 的目的支撑自然随零位移改变，不用 A 的真值／预测目的区域筛样。两臂共享现行相同 motion-loss 预训练；融合阶段 motion 冻结，没有可优化的 motion loss，不能把加一个常数损失称为“联合训练”。原 O 是另一个冻结参考。A−Z 衡量此连接训练政策的效应，A−O 衡量实用收益；门自己修正前景的效应由 Z 控制。

**同 checkpoint 干预。** 固定 source、O logits、预测 d 和权重，①令 d→0 后重算 S/W/门，测整条连接响应；②固定原预测下的门值，再令 d→0、重算 S/W及无覆盖回退，测门不重新响应时的几何路径变化。两者之差仅是该固定网络的门响应分解，不是唯一因果归因。另将融合关掉必须逐元素回到 O。记录输出变化、门激活、源／目的支撑、碰撞／边界质量、FP/FN；不能以零位移造成分布失配后的下降代替 A/Z 训练比较。时间错配可作补充，不能单独证明运动正确。

**这一阶段的价值和不足。** 冻结前两模块可低成本判断现有运动是否可用，避免把 O 继续训练与新增监督混在一起；小门不能补救缺失源形状，也不能证明任务损失学到了运动。真正联训下一步至少需同预训初始化的 A_joint/Z_joint：相同 motion loss、占据损失、更新及参数范围，唯一差别仍是占据梯度能否经 splat 到 d；O 先继续冻结。实测非零 `∂L_occ/∂d`、最后时域梯度与运动 EPE，防止 gate 关闭或位移成为非物理修补。若再解冻 O，须另有同预算 O continuation／同解冻范围 Z，不能归入此前冻结比较。

**判读与唯一转向。** 同时看 A 对 O/Z 的原任务四未来 GMO，以及所有模型共用、包含漏检的输出运动指标；头自身 box-proxy EPE仅诊断，不能赋给没有 flow 输出的 O。单 seed11、历史开发曝光如实保留。若监督误差尚不能优于相同支持的零运动，或高运动组失败，先停止扩大融合，转向**截至 t0 的过去帧局部关联**补足运动输入，保持标签／传输不变重新对照；不是增加记忆槽或径向速度当完整运动。若 EPE 已好而 A不胜Z/O，则否定本轮概率源连接，不靠改阈值／GT mask 救分。

已有 [CRT-Fusion](https://github.com/mjseong0414/CRT-Fusion)、[BEVerse](https://github.com/zhangyp15/BEVerse)、UniAD 和 OccFlowNet 先例；本设计不是模块组装新颖性。限定依据见 [运动文献审查](literature_motion_forecasting.md)、[雷达文献审查](literature_radar_motion.md) 和 [真实 oracle 结果](oracle_transport_train16_结果与决策.md)。科学贡献须来自何种运动证据及支撑条件使连接成立／失败的受控结果。
