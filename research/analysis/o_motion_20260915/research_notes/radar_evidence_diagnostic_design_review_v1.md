# Radar 8 通道是否提供幅值之外的风险区分：有限诊断审查

2026-09-16，待执行方案；本页只读源码与已有结果，没有连接服务器、读取 dev 或运行模型。**建议开展一次 CPU-only train512 诊断，不立即拟合 gate。** 已有结果中，2 s D 速度幅值 AUC 为 0.610989；预定“更平滑更可靠”方向的邻域速度差 AUC 为 0.360027，不能事后反向包装为成功。新问题限定为：显式雷达摘要在固定 D 幅值层内，是否还与未覆盖点 D fallback 的收益相关？

## 最短可执行协议

1. **认证后读取输入。** 固定原 train512 / 256 scenes、D 提取与 sparse 支持；沿 native index 认证每个 `inputs.pt` 的 SHA/bytes，以 CPU 反序列化，只导出 `radar_bev`。逐项核 `[1,8,200,200]`、float32、有限值及原 `native_radar_tensor_sha256`；digest 必须沿原 dtype字符串、shape列表 JSON、连续字节定义。无需重跑 D、O 或 encoder，不打开 native `targets.npy`，不调用 CUDA。仅用已完成 D 提取中的四时域位移与原标签作后续配对分析。
2. **先定义输入场，再接标签。** 雷达轴为 `[B,C,Y,X]`；D/source 为 XYZ C-order。对原 flat index：`x=idx//3200`，`y=(idx//16)%200`，读取 `radar[0,:,y,x]`。使用原同一 XY cell，首轮不加最近回波搜索、邻域扩张或 GT 框池化。认证身份/顺序后，与原提取的 owner、D 共享速度及 sparse source index 精确配对。
3. **完整评分支持不变。** 主风险集合仍为 `owner<0 & original_valid[h]`；收益仍为 `||gt_xy||−||D_xy−gt_xy||`。保留全部 43189 个对象×时域记录、原 future-missing 规则，以及 D/CV/fixed-blend/zero 原物理表。雷达缺测与饱和只决定某个诊断量是否定义，不能删掉对象或替换完整分母。

## 最少信号及事前方向

`presence=c0` **只作缺测分层**，不把无回波赋予静止标签。下表“正向”表示分数越大越倾向 `收益>0`；方向只是假说，结果不佳时不得翻转。

| 量 | 定义、有效域 | 固定方向 |
|---|---|---|
| 雷达平均速度模：主要 | `20*c6` m/s；有回波，注明截断 | 正 |
| 相对零速度的雷达摘要一致性优势：主要 | `||vR||−||vhat_D,xy−vR||`，`vR=20*(c4,c5)`；有回波 | 正 |
| D 与雷达均值速度相符程度：次级对照 | `−||vhat_D,xy−vR||`；有回波 | 正，即较小差异有利 |
| 回波数量摘要：探索 | 原 `c1`，有回波；保留 32 次以上饱和并列 | 正 |
| 平均年龄摘要：探索 | `−0.5*c7` s，有回波；保留年龄截断并列 | 正，即较新有利 |

有回波时上述量可由编码摘要定义；`abs(c4)==1`、`abs(c5)==1` 或 `c6==1` 单列饱和标志，完整支持不删点，并分别报告饱和/非饱和的 AUC 与贡献。饱和点上的数值是**截断摘要差**，不能当精确测量残差。第二个量更贴合 D-vs-zero 问题，但只是“更接近该雷达均值”而非真实收益；它满足 `|s|≤||vhat_D,xy||`，其符号由 `2*vR·vhat_D,xy−||vhat_D,xy||²` 决定，仍强依赖幅值。D 零幅值时 s 自然为零，不排除；无回波时不定义 s，不能代入 vR=0 制造负证据。不把 s=0 用作推理阈值。计数/年龄可在饱和处排序并列，不能反演精确原值。RCS、高度和“均值速度模−均值向量模”首轮仅保留原数据，不增加评分特征、协方差或可靠性解释。

沿已冻结 D 幅值 bins `[0,.1,.5,1,2,5,10,∞)`，逐四时域报告上述固定方向的 weighted AUC、每场景可定义 AUC 的 median/IQR、连续收益及正收益/负代价贡献。每点权重仍为 `1/n_original_valid_object`；AUC 只排除恰好零收益，完整物理统计不排除。分别披露无回波、有回波未饱和、有回波饱和的点数、原对象数、权重质量及完整分母贡献，不给缺测残差填零。固定分箱只是粗幅值控制，不能据此宣称完全消除幅值混杂。无拟合、无阈值搜索、无“最佳时域/方向”选择。

## 解释与执行风险

- **单位与时序：** 原缓存把最多五个 sweeps、五个 radar sensor 的有效点合并到当前 LiDAR R 格。`c4/c5` 是旋转到 R 的 ego-compensated vx/vy 均值并除以 20 后截断；`c6` 是逐返回速度模的均值，不能用前两者的模替代。点位只作坐标变换，没有按物体速度补偿其多扫时间差；当前 cell 可含过去不同位置、多个物体和传感器的混合。
- **不作 LOS 推断：** 八通道没有逐返回 LOS、传感器原点/ID、径向速度或方差。`D−radar` 只是两个 XY 估计的差，不能称 Doppler 残差、完整物体速度真值或运动可观测性定理；正确的 D 也可能与混合/陈旧雷达均值不一致。
- **重复高度不是重复测量：** 同一 `(anchor,x,y)` 的各 z 点共享同一个雷达摘要；保留原物理权重，不把它们算成独立回波。另报不同 XY cell 数和对象×XY 数；场景汇总用于描述稳定性，不做逐体素独立显著性检验，也不通过去重改变主分母。
- **不是新增独立信息：** D 输入已融合 radar encoder；显式读取摘要只检验已有观测是否保留可用于校正 D 的信息，不证明引入新传感器或统计独立证据。train512 已被 D 训练见过；即使正向，也不是 D 的场景外泛化。GT 速度组、未来位移与真实实例只用于评分，绝不成为雷达特征输入。

**停止与下一动作：**若幅值层内没有稳定额外区分，或条件性好看只来自很小的回波支持，就结束该 8 通道摘要方向，不翻转分数、扩半径或按 dev 调规则；结论只是否定这些压缩摘要，不能否定原始雷达/时序测量。若有区分，先锁定训练侧可推理规则再考虑连接实验；它仍必须保留 O 的稠密通路与完整占据/运动支持。物理风险排序或子集 AUC 改善不等于未来占据改善，更不构成超过 O 的联合目标。
