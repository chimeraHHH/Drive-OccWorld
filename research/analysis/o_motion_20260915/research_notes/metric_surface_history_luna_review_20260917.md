# 冻结表面运动基准的独立核查

2026-09-17，GPT-5.6-Luna 子 agent，根 agent 对照源码复核。只读检查，不是独立重跑模型。

1. Metric3D 输入尺寸、keep-ratio、padding、RGB mean/std、去 padding、align_corners=False 上采样及 scaled fx/1000 的恢复与固定版本官方 hubconf.py:155–199 一致。
2. current→past flow 的符号、两次 lift 到共同 t0 LiDAR 坐标、实际相机时间差、曝光至 t0 的恒速配准没有发现明显实现错误。曝光配准仍是恒速近似。
3. FB 是二维光流前后向残差，不能检查深度的跨时一致性。子 agent 的静止场景反例：相机/像素不变，两帧深度10和10.2米、相隔0.5秒，FB=0仍产生0.4m/s假三维速度。这是解析反例，非数据集测量。
4. 固定图像网格与三维速度预测不读取GT；评分位置来自原GT当前框内虚拟材料点。故只能称输入独立的预测场在GT定义原人口上的诊断，不能称真实可见表面GT、完整部署结果或占据性能。
5. 1米三维最近邻可能把多个内部材料点关联到同一表面/背景点。须保留全部原人口和固定回退，报告支持率与距离；误差可能含深度、对应、归属及外推误差，不能单独归因某个网络。
6. 主比较保留所有方法的nominal horizon；actual-time只是敏感性分析，因为原D输出仍针对nominal horizon。

根 agent 纠正：低FB通过率本身不能归因深度抖动；FB与ROI的交集才受预测深度影响。该基准没有跨时深度约束，这是待比较的科学假设，并非已确认漏实现了官方功能。
