# 共享运动状态实验：研究问题与终点解释

2026-09-16。写于正式 Cpl/Fix 训练期间、开发集评价开始之前。本文整理研究解释，不修改已冻结模型、损失、训练预算、评价域、统计方法或晋级门槛。全部新候选性能仍未知。

## 研究问题收紧

当前要检验的是：**当运动变量必须同时解释材料点位移和未来特征的空间位置时，能否在强常速度参考之上学到有用修正，并使未来占据受益？**

旧速度条件化路线中，固定终点的速度置换/清零几乎不改变占据和物理结果。这支持停止那条具体连接路线，不能推广为雷达无用、运动无用或所有隐变量表示都无效。原结果见 `../object_state_velocity_assignment_结果与决策.md`。

新候选把当前预测对象的同一未来位姿用在两处：一处作用于源材料点，产生可计分的位移；另一处决定未来 BEV 对象特征的连续空间权重。这个设计给运动变量增加了任务内的可检验作用。不过，O 的稠密路径仍然存在，解码器仍可能绕过对象残差；不能仅凭结构连通或非零梯度宣称模型真正依赖运动。

## 当前对照到底能回答什么

| 比较 | 可回答的问题 | 单靠该比较不能证明 |
|---|---|---|
| Cpl / Fix 对 O 的原未来 GMO IoU、FP/FN、移动及高速召回 | 新的对象模块加原 head 适配是否改善原任务，是否付出漏报代价 | 物理位移更准、雷达独立贡献、共享地址的独立效用 |
| Cpl / Fix 对 CRN-CV 的完整支持物理 EPE | 是否优于已经很强的当前检测速度外推，是否超出更换基底的收益 | 优于 O 的 flow；O 没有可认证的同口径 flow 输出 |
| Cpl 对 Fix | 让学习位姿进入空间核地址是否产生额外效用 | 所有运动信息有/无的比较；Fix 的值向量仍携带学习位姿 |
| 分组、分时域、完整覆盖与转移统计 | 收益来自哪些对象/时域，是否隐藏静止对象退化、漏检或到达区域失误 | 未观测的真实稠密场景流、训练种子稳定性、独立测试泛化 |

两臂的物理损失、参数容量、初始化、样本/RNG 顺序一致；训练后参数轨迹可以不同。Cpl−Fix 是这一训练设计的匹配比较，不能直接当成在同一最终权重上切断一条边的干预。若完整开发结果值得进一步验证，固定权重干预是后续机制诊断的候选，必须另行固定操作、支持与评价，不能看结果挑干预方式。

## 预先明确的结果解释

以下沿用原目标，不新增数值阈值。效应量、原场景配对区间、各组支持和风险代价一起判断；小而非零不能自动晋级。

| 完整终点呈现的模式 | 合理解释与下一步 |
|---|---|
| 占据改善，但物理修正没有超出 CRN-CV | 对象先验或 head 适配可能有用；不能称运动预测改进，不据此扩展当前路线。 |
| 物理误差改善，但占据没有收益或漏报明显恶化 | 辅助读出学到了修正，但主任务没有获得可接受的效用；保留 O，诊断任务连接。 |
| 两臂都同时改善，但 Cpl−Fix 接近零 | 支持共同对象表示/物理修正的效用，不能主张学习空间地址是关键机制；若值得全量验证，应如实保留该负对照结论。 |
| Cpl 对 O、CRN-CV 及 Fix 有一致且有意义的收益，风险结果可接受 | 可以讨论晋级，并单独固定更广验证；当前暴露开发集仍不是最终发表证据。 |
| 两臂都没有有意义的联合收益 | 结束本候选，按完整误差分解判断信息来源、任务定义或连接设计；不靠增加训练轮数、换种子、删难样本来掩盖结果。 |

## 近期文献对贡献定位的约束

`gast_input_geometry_and_evaluation_boundary_v1.md` 已核到先行的位姿驱动特征构造；已有 `uniad_motion_occupancy_overlap_audit_v1.md`、`occflownet_motion_source_boundary_v1.md`、`selfoccflow_task_and_coupling_boundary_v1.md` 也分别限定了运动/占据交互、运动引导监督和邻帧 flow 的重合边界。因此本轮首先是科学效用检验，不是“首次引入运动”的验证。

新增 `dego_motion_coupling_boundary_v1.md` 核查了逐 Gaussian 几何/特征与渲染监督的耦合，`mogaf_forecasting_boundary_v1.md` 则核查了逐场景重建后的分组轨迹外推。前者的发布评价是当前占据，后者不是我们原传感器条件下的跨场景占据预测；这些任务差异需要保留，但不能把任务不同本身当成新颖性证明。

有希望的贡献需要落在三个可验证层次：同一个运动变量确实被任务使用；它带来强物理基线之外的误差下降；这种下降能改善完整未来占据并交代风险代价。即便三个层次成立，也还需要完整验证、适用边界和更严格的先行工作比较。当前不能把它们写成已完成的论文贡献。

材料点标签由对象刚体运动构造，是物理代理而非传感器直接测得的稠密流；缺框和未覆盖点仍保留在完整分母。改进这一代理不等于已解决形变、交互或所有遮挡运动。单 seed 11 的场景 bootstrap 反映开发样本的变动，不覆盖训练随机性的变动。

另见 `../fixed_owner_error_floor_dev200_v1.md`：由既有 CRN-CV 完整记录计算的移动组 2 秒未覆盖误差贡献为 1.80637 m，占其完整 XY EPE 的 53.34%。该项对当前固定 owner 物理分支不可消除，揭示了表示限制；但已覆盖部分仍有改善空间，不能以此替代候选的实际有效性检验。这是旧参考的误差分解，不是新候选成绩或新晋级指标。
