# 内容读出与递推动力状态分离：T/J 固定对照

日期：2026-09-17。训练前冻结。依据为上一轮完整 train4 学习曲线和内容/位移交叉矩阵，不把新协议视为实验结论。

核心问题：同样的递推动力网络，future occupancy 是否必须依赖自由内容改写，还是固定当前内容经学习的运动传播也足够？

保持 S_h=S_(h-1)+f(S_0,S_(h-1),h)，d_h=d_(h-1)+0.5 g(S_0,S_(h-1),h)；J 的 renderer 读取 S_h，T 的 renderer 始终读取 S_0。两者按同一 d_h 在原网格 splat，再用相同冻结 decoder。T 不 detach 或删除 S_h，也不冻结 content_increment，因此其递推动力表达能力保留；早期 increment 仍经未来位移接受梯度。最后一步 increment 对 T 输出无路径，用于检查直接内容读出旁路已移除。

两组均从认证的 shared codec/零初始运动开始，全参数初始值相同，encoder/decoder 冻结，52720 trainable 参数，原 CE+Lovasz+0.1 physical，seed11、相同四样本循环、各 512 updates 和 0/32/128/512 评估，保持原数值策略。J 新鲜重跑作为同步对照，不能默认其轨迹与前一非确定性 CUDA 运行逐位一致。此处仍无开发集/O 结果。只改变 rendered source 的选择，不改变 loss、GT、参数数目或 recurrent 容量。

CPU 非零权重图检查在读训练数据前运行：free 与原生 logits 完全相同，同参数 T/J 位移完全相同，T zero 恒等于 t0，T 最后 increment 无直接梯度但早期 recurrence/velocity 梯度存在。实际数据也检查 T zero persistence，原分母及 t0 预测固定。独立子 agent 已核对源码，无阻止启动的问题；实际运行仍以服务器检查为准。

## 决策边界

- T/J 的占据和运动都接近：在这四个训练样本上自由内容改写不是必需，进入较大数据对照。
- T 占据明显更低、运动相当或更好：固定当前表示/decoder 的限制或 J 内容改写参与解释，不能声称准确运动损害占据。
- T 运动也更差：读出约束改变了优化，不能唯一归因于内容容量。
- 两组的 stationary 误运动仍必须与零位移及原对象人口一起报告。

这是这个问题最后一项 train4 控制比较；不围绕这四个样本继续调系数或结构搜寻漂亮数字。下一阶段使用原 train512/256 scenes 拟合共同 current codec，再锁定同预算的 transport 与直接未来状态对照。先明确候选在完整训练人口中的当前表示、稀疏运动和计算开销，再冻结未参与选路的确认场景；已有 dev200 是开发集，不能改名为独立测试。若 fixed-current 限制明确，不把它硬推为最终模型，而设计持久内容与新出现/遮挡变化的分离对照。

T 的 C0 是包含背景与混合体素的 dense latent，不是已恢复的物体材料身份。没有真正的新生内容模型，也未接入独立雷达 Doppler 观测。用户提出的少视觉历史贡献仍需真实输入窗口、Doppler 消融和系统成本实验，与本轮保持区分。
