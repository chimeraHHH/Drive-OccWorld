# 显式对象运动状态与两种空间读出的独立设计评审

2026-09-16；**条件性草案，未实现、未训练，不改变当前晋级标准**。本审查未读取 N/P/Z 终态成绩；以下选择依赖其真实结果。

**最强反解释。** `FutureStateMotionReadout` 在源位置拼接 F0(x)、Fh(x)，可以学习源点位移，这种参数化本身没有证明“地址错了”。生成特征也不是已证实具有固定物理参考系的 occupancy 图；原 native 几何先验、监督参考系及 learned offsets 的问题必须与源/目的索引、实例对应分开。conditioner v2 已显式输入对象的 p0+h·v，32 latents 也不等于必然丢失位置。V/G 增量很小，仍可能来自有效状态未被优化利用、D 残差基底及零初始化路径、目标权重或框质量，而非唯一的空间关联缺陷。CRN-CV 的 2 s moving XY EPE 为 3.38674 m，D 为 4.20824 m：若新结构仅直接输出 CV，优于 D 不能算学到了更好的运动。

## 单候选：CV 残差刚体状态，同状态驱动源点位移和未来空间特征

保留每个当前预测框的 index，不压成无对象身份的场景槽。全部八类原预测框及其原 score/顺序进入，既不按 GT 匹配筛选，也不新增分数阈值。当前位置、完整旋转、wlh、类别、score、预测速度，以及在**当前**观测 BEV 上由预测框取得的特征，编码为对象状态；按名义 h 预测中心修正 δc 和零初值旋转向量 δω。构造

`c_j(h)=c_j(0)+h*v_j+δc_j(h)`，`R_j(h)=Exp(δω_j(h))*R_j(0)`。

第一轮不另学尺寸：wlh 只确定当前局部坐标/空间尺度。中心运动与旋转绕几何中心明确分开，旋转仍是假设的框刚体运动，不称真实点级 scene flow。

* **物理读出按源地址。** 对任意 t0 点 p，沿已验证 CRN-CV 规则：包含它的 GMO 预测框中取最高 score，tie 保留原导出顺序；归属一经当前输入确定，对所有 h 固定。局部材料坐标 ξ=R0ᵀ(p−c0)，输出 `c_h+R_h ξ−p`。δc=δω=0 时应直接走原 CV 向量 `h*v` 的实现，避免旋转往返浮点误差，初始完整场精确等于强 CV。未被任何预测框覆盖处始终输出零，不偷偷换成 D。所有原稀疏合法源点继续计分，漏检/重复框错归属会真实受罚。
* **占据读出按未来空间地址。** 在原 GT/evaluator 的 t0-R 输出格点 x，以 `R_hᵀ(x−c_h)` 和对象状态构造可学习对象特征，汇聚后进入原占据读出之前的特征通路；原 native future head/读出照常训练，不只改最终 logit。使用连续空间特征/权重，不把输出硬裁在框内，也不将 GT 归属送入前向。新特征投影零初始化保留初始 O。此处 R 是新对象场和监督输出的显式坐标契约，**不宣称旧 native hidden features 已严格处于 R，也不改其 SE(3) 路由**。
* **覆盖余量。** O 稠密通路始终覆盖全格，新生、漏检、遮挡补全不受预测框门控；空框集合对象特征为零，仍输出 O 通路。未来才出现而 t0 无合法材料源的对象仍在原共同占据评价中，不能凭空构造 forward-flow 标签。当前有 GT 源但未被预测框覆盖的点保留零预测及原误差；未来出 ROI 的原有效 flow 标签仍保留。该选择可能限制物理上限，必须如实保留覆盖统计。

**CV 精确接口不能降格。** 全部 `200×200×16` 源格点的 CV/owner 应由原 float64 centered boxes、G0、完整 3D membership 和原 `predicted_velocity_field` 规则一次生成，严格 `>` 更新最高 score 以保留同分原序，未覆盖为零；此缓存不读 GT。学习部分才使用 packed27。若要声称初始逐位等于原 CV，必须保留原基底精度与算术，不能先转 float32 再回转；零残差路径直接返回原基底。监督仅在最后取 `points[source_flat_indices]` 的既有位置，不参与场定义。

## 必要匹配控制：共同 CV 基底，只断开学习修正到占据地址的前向边

两臂输入、全部框、原 score、容量、初始化、物理输出与物理 loss、原 O 六项占据 loss、whole-head 更新范围、订单/预算/seed11 全相同。候选占据查询使用学到的 `(c_h,R_h)`；控制仅在**占据地址**使用 `(c0+h*v,R0)`，其物理头仍预测并监督相同 δc/δω，对象特征值通路仍可学习。不得在控制中把未来地址故意当源地址，也不额外增加第三训练臂。

这样识别的是“学到的运动修正显式改变占据空间查询”这一条连接的增量；控制本身有正确 CV 几何且可以通过特征学习修正，因此是强控制。两臂物理收益都必须同时面对完整支持下的 CRN-CV，占据面对 O；不能用赢弱 D 或错配控制代替共同改善。特征值通路仍可隐式编码运动、两个模型训练后会共同适应，故该比较不是全部运动信息的唯一因果归因。零初始化的早期梯度延迟同样存在，不能把一次首步零梯度解读为结构无效。

## N/P/Z 会怎样改变选择

| 同一最终 V checkpoint 的真实现象 | 对下一动作的影响 |
|---|---|
| N 相对 P、Z 在物理和占据均出现有实际意义的优势 | 原结构已经使用正确关联；降低“缺显式地址”为主因的优先级，先解释现有效益与 CV 差距，不自动换结构。 |
| N、P、Z 都只产生微小效应 | 支持原模型利用速度不足，但不区分压缩、优化或关联原因。上述显式 CV 基底/双读出是可检验替代，仍不是已证明修复。 |
| P 明显更差，而 N 与 Z 接近 | 只能说明错配速度可破坏模型；P 会破坏类别、朝向、位置与速度联合分布，有 OOD 影响，不能据此声称正常速度有益。 |
| N 只改善物理而占据不受益，或反向 | 显示目标连接/权衡仍在；候选的显式共享位姿边值得检验，但不能将一项收益升级为联合目标成功。 |

不增加任何 N/P/Z 或 full 晋级阈值；统计非零与实质效应必须分开。

**先行工作边界。** UniAD 已保留 agent 轴，将 motion/track/position 融合给 BEV，占据还有受监督的实例 mask attention；“对象 query + motion→occupancy + 联合训练”不是新贡献。这里唯一待检验的窄差异是对本任务的任意源材料点 forward 位移与未来 Eulerian 占据，使用同一预测刚体状态、显式两种地址及共同强 CV 对照。即使成功也先是本系统的结构证据，尚不足以主张 ICLR 新颖性。原检测器成本、单训练 seed、暴露过的开发集及原虚拟刚体标签边界不变。
