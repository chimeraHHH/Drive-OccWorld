# 从文献调查到实际未来观测对照

2026-09-17。本轮调研及其范围见 [综合报告](world_model_research_direction_v2_20260917.md)。以下是追加的执行设计，状态与结果以对应服务器 receipt 为准。

## 新实验增加了什么

已有 C/O 特征×读出交换在 dev200 得到 CC 13.7386、CO 13.7789、OC 14.7015、OO 14.6640% future macro GMO。它说明本次 C/O 差异主要沿预测特征路径体现，但存在共同适应，不能唯一分解因果贡献。见 [原报告](../../m0_improvement_20260915/server_results/campaign_readout_transition_v4/development/report.md)。该实验、K/B 物理反馈与共享刚体状态都未使用真实未来传感器编码状态。

最终 `future_observation_readout_train16_v5` 固定原训练顺序前 16 anchors / 8 scenes，比对：

- 固定 O 的原生四步未来预测。
- 固定 O 的 t0 logits 在原参考系保持不变，即静态世界持久化。
- 在每个未来时刻，用同一冻结编码器读取该时刻及之前两帧相机和该时刻原生雷达；同一 O 分类读出产生局部 occupancy logits，再用完整 SE(3) 映射到原 t0 参考系。超出未来网格可插值区域时回退到 t0 持久化。

第三项是特权观测诊断，包含未来信息，不是可部署模型，也不是保证优于 O 的数学上界。编码器、雷达融合和读出均不训练，O 的预测分支仍只用原输入及原协议给定的未来自车条件。

## 为什么先比输出而不直接互换 BEV latent

O 的 256 维 BEV 没有独立高度坐标；把它当成完整三维体素特征旋转会混淆通道语义。新实验在共享读出之后对具有明确 XYZ 轴的 logits 做三维对齐。它验证的是未来观测能否改善任务输出，并不直接认证 future BEV embedding 的替换或 L1 蒸馏目标。

代码检查包括：恒等/正 X 位移/90° 旋转的解析网格；真实当前帧重编码与旧 cache 的 BEV 数值一致性；独立 dataset 位姿与 cache 变换一致性；真实时间差及同 scene；O 原始全分辨率混淆完全复现；结束时冻结参数摘要不变。所有模型前向完成后才读取分离的 occupancy targets。

train cache 的实际提取器使用 `cfg.data.test` pipeline，仅替换为 train annotation（`native_state_cache.py:492–496`），因此不是带训练随机图像增强的 cache。子 agent 的这一初始疑虑已按真实 producer 源码纠正。

## 指标和解释边界

主指标仍是每个未来时域各自池化混淆后算 GMO IoU，再平均四个时域；另列跨时域池化 IoU，不能混用。报告 GMO recall 不等于实际移动物体 recall。没有物理运动输出，不报告新 EPE。

完整 ROI 分数包含明确的持久回退。同时比较所有方法在相同几何网格交集中的结果。这里的 `support` 仅指 SE(3) 后的可插值网格区域，不表示实际可见表面、传感器覆盖或观测可信度。16 个训练 anchors 不能证明泛化收益，也不能凭某个 teacher 差值唯一确定表征、状态转移或解码瓶颈。

若匹配读出的未来观测明显更好，将研究可学习的未来场景状态及其任务用途，先解决坐标与表征兼容性；不能仅凭此添加蒸馏 loss 就声称获得方法创新。若未来观测也弱，应检查感知/读出和场景覆盖，再与合法历史对应路线比较。现有 O/M0 保留，S3 不重启，单 seed11。

## 执行记录

v1 在 GPU 几何恒等检查处停止，误差 0.02929735；当时测试启用了 TF32，而正式输出重采样前已关闭 TF32。尚未构建模型、没有训练或 anchor 结果。v2 仅使解析测试与正式重采样使用一致的 FP32 matmul 策略，保留 1e-4 容差；同时在汇总中明确区分 macro 与 pooled 指标。失败输出没有复用，服务器任务各自独立且有 31 分钟外层超时和 32 GiB 分配上限。

v2 另在首次 teacher 前向前发现原生 `CustomCollect3D` 会为缺失字段输出 `None`。v3 改为检查标签值为空并限定只传 `img/img_metas`，与原数据路径一致。v3 前四个 anchor 当前 BEV 误差均为 0，但第五个 anchor 的真实第二未来时刻为 0.899625 秒，触发额外的名义 0.5 秒间隔假设。原数据的四个未来时域实际范围分别为 [0.448978, 0.550170]、[0.899625, 1.000857]、[1.400054, 1.600271]、[1.899949, 2.100140] 秒。

v4 保留原样本、帧槽位与标签，改以原始 nuScenes 连续 sample 链、annotation 文件 SHA、真实时间戳及位姿核验配对；不是放宽一个误差阈值后默认配对正确。汇总仍沿原协议标称时域，另保存实际时间差，并在结果复算时与既有物理标签的时间差逐一对照。前三次失败输出均不并入 v4 结果。
