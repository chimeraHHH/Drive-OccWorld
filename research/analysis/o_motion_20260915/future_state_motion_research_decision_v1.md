# 从冻结输出修正转向可训练的运动状态

本轮研究目标仍是：超过固定 O 的原未来占据任务，并获得更准确的运动预测。R/R0 的开发集结果不满足这一目标，不启动其完整 5119 样本评价；保留全部权重与负面结果。

实际 R−O 的未来 GMO 为 +0.537171 pp，场景配对 95% 区间 [0.322608, 0.814585]，但真实速度 >0.5 m/s 的正体素召回为 −2.739691 pp，区间 [−3.607350, −1.924132]。R−R0 的两项区间均跨零。R 增加 53984 个 moving FN，不能用减少全域误报抵消这项事实。固定 t0 下的 transition 10 IoU 降低还受到原 t0 误报的影响，不能将该下降直接解释为物体腾空错误；独立原始计数拆解见 [结果解释](future_feature_residual_result_interpretation_v1.md)。统计没有更换原 GMO、阈值或支持集合。

新增同点物理诊断提供了下一动作的依据。在有历史且有未来有效标签的同一源点集合中，2 秒 moving 组 1192 个 anchor-instance 的 D / 历史真值 CV / zero 平均 XY EPE 为 4.148792 / 1.185450 / 7.489120 米。CV 没有使用未来位姿或未来真实 dt，只用 t0 与最近有效历史中心、真实历史 dt 和名义预测时域。缺历史、无唯一源点和缺未来标注均保留账本。它说明给定可靠历史状态后仍有较强的可预测结构；不能证明真实图像雷达能恢复这些特权状态，或将差距唯一归因于某个网络模块。[同点诊断](history_state_predictability_diagnostic_v1.md)

## 选定的下一项判别实验

问题是：**物理运动监督能否改变原生未来状态生成器，从而同时改进占据与位移预测？** 此次允许被改变的是 O 的可训练副本；参考 O 和 M0 均不改动。暂不引入对象 slots、Hungarian 分配或新的实例掩码，以免同时改变标签表示、匹配、容量和状态更新后无法定位收益。更完整的对象状态路线保留为后续候选，见 [原论文与作者代码研究](dynamics_representation_next_routes_v1.md)。

| 项目 | K：物理监督进入未来状态 | B：切断物理监督到未来状态 |
|---|---|---|
| 初始化 | 原 O 最终 future_head 的独立副本 | 相同 |
| 占据优化 | 原 CE[1,5]＋Lovasz，原三层、t0＋四未来 | 相同 |
| 占据输出 | 原 native forward 直接返回 | 相同 |
| 运动初值 | 冻结最终 D 位移＋零初始化新读出修正 | 相同 |
| 运动读出输入 | 原生 t0 与每个未来的 terminal 特征、名义时域 | 数值相同，但输入 detach |
| 物理监督 | 原全部合法 sparse 材料点、刚体框位移、原分组归约 | 相同，读出自身仍训练 |
| 唯一实验区别 | 物理损失可回传到 future_head | 该路径断开；占据损失仍训练 future_head |

新读出共享两层 Conv2d，输入 256 当前通道＋256 未来通道＋1 名义时域，宽度 128，输出每高度 XYZ 修正，共 745392 参数。D 不参与优化；不搬运原占据预测、不接终端占据残差，不用 O hard-positive 或 GT box 掩码限制前向。所有原合法源点用于监督，未来 GT 位置不用于取特征。原生 token 轴仍为 y*X+x，位移输出为固定 t0 LiDAR 米制 XYZ。特征的原生几何语义保持原模型定义；同位置拼接本身不代表已经建立物体对应。

两臂均训练完整 future_head，因此更新后的原生 t0 预测允许变化，必须报告当前帧代价；不能沿用 R 全程 t0 不变的检查。初始化的占据输出必须等于 O、物理输出必须等于 D。新的 readout 末层为零时，第一次物理梯度到上游为零是正常现象；须在真实一次读出更新后检查 K 的未来状态/transition 梯度及 B 的断开路径。

预检仅使用 seed11 原排列前 16 次暴露，accum4、四次更新、配对 dropout RNG，结束丢弃临时权重，不读开发分数。future_head 沿 O 的学习率 1e−5、clip35、warmup50；新读出沿 source-motion 的 1e−3、clip10、warmup25；均使用既有 512 步的调度前四步。物理和原占据系数均固定为 1。实际吞吐、峰值和非零梯度尚须原生预检，正式训练的执行资源在该实测后冻结。没有多 seed 或自动扩展更新数。

## 怎样决定继续

工程预检只验证真实连接与运行成本，不证明性能。正式比较必须同时给出 K/B/固定 O 的原未来 GMO、全部 FP/FN、各时域和真实运动组覆盖，以及 K/B/固定 D 在完全相同 sparse 支持上的物理误差；不为 O 虚构原生 flow。K−B 解释物理监督进入未来状态的增量。只降低辅助 EPE、只提高 GMO、或只提高 recall 均不足以完成目标。占据与物理收益得到支持后，还需要原 5119 anchors / 150 scenes 的共同完整验证；原验证已暴露、单 seed 的边界保留。

当前状态和冻结 D 都可能成为读出的捷径，即使物理梯度非零，也不能据此宣称学到了实例对应。若 K 没有比 B 带来有用的共同收益，记录这个有限监督接口的结果；不把它扩大为所有对象状态学习无效，也不继续盲目叠加相同冻结输出修正。

## 先例与本项目推演

UniAD 的原论文在 OccFormer 中将对象运动查询与稠密未来状态共同用于占据生成。此次核对官方 v2.0 commit `609ee083ea51c3521c323f1279dfc4cee0e60467`：`merge_queries` 融合轨迹和跟踪特征，只有位置分支默认 detach；预测的二值 attention mask 也 detach，不能笼统声称每条路径都可微。代码保留查询特征到未来状态和实例占据的路径。[原论文 §2.3](https://arxiv.org/pdf/2212.10156)、[官方 occ_head](https://github.com/OpenDriveLab/UniAD/blob/609ee083ea51c3521c323f1279dfc4cee0e60467/projects/mmdet3d_plugin/uniad/dense_heads/occ_head.py#L271)

这提供共享表示与对象交互的先例，不保证本项目收益。K/B 是针对现有系统的受控表征实验，不是 UniAD 复现，也不把“增加物理辅助损失”作为已成立的新颖方法。PowerBEV 的独立预测支路和 FipTR 的跨时域实例匹配边界已在上述研究报告中分别核对。没有执行或训练这些外部模型。[UniAD 来源快照](motion_state_joint_source_reads/sources.json)
