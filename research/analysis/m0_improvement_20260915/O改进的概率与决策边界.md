# O 改进的概率与决策边界

2026-09-15。完整验证正在运行；此处只使用完成的开发结果、已冻结源码和原始论文，不读取部分 full 性能，不修改模型或评测阈值。

## 当前能支持什么

O 的固定最终权重在开发集比同精度 M0 高 0.7574 pp，也比同预算原目标继续训练 C 高 0.9254 pp。这证明的是当前实验条件下学习配方的效用，尚不能识别收益来自更好的未来表征、空间排序、概率估计还是决策边界。O 修改整个 future head 的训练目标，实际测试仍用原生 argmax；没有靠事后阈值拟合取得这个差值。

还有一个应避免混淆的对照：t=0 的 O−M0_fp32 是 −0.15914 pp，但 O−C 是 **+0.08517 pp**，对应已有场景配对区间 [+0.05842,+0.11456]。因此，相对 M0 的当前代价真实存在，但不能写成“删除 sem/geo 导致当前预测比原目标更差”。后者与完成的同预算对照不符。

## 直接相关先行工作

Koyejo、Natarajan、Ravikumar、Dhillon 的 NIPS 2014 论文处理总体混淆矩阵的线性分式效用。§2 Theorem 2／式(5)给出依赖最优效用的条件概率阈值，Jaccard 的特例为 J*/(1+J*)；§3 的两类算法分别学习概率后选择阈值、以及用非对称损失学习决策，§3.1 给出条件性一致性。原文假设 iid 抽样；这些结论不能直接充当有限预算、相关占据体素、复合损失与共享时域神经网络的保证。[原论文，PDF pp.3–6](https://papers.nips.cc/paper_files/paper/2014/file/98053046e0dce5c7d946c67b96a85e18-Paper.pdf)

MonoScene §3.3.1／式(4)–(7)构造基于 soft precision、recall、specificity 的 scene-class affinity。我们的 sem/geo 继承的是这一类统计约束，不能把它们称为全数据未来 IoU 的精确替代量，也不能仅凭 O 一次改善否定它们在原多类场景补全任务中的作用。[作者项目与论文入口](https://astra-vision.github.io/MonoScene/)

## 本项目的推导：类别权重并不等于自然概率

先看一个明确受限的理想情形：只优化全局加权二分类 CE，正类权重 5、负类权重 1，函数空间不受限且达到总体最优。对自然正类条件概率 η(x)，逐点求导可得

```
p*(x) = 5η(x) / [1 + 4η(x)]
argmax 即 p*>1/2，对应 η>1/6。
```

所以即使这一理想 CE 完全优化，它的原始 softmax 也不是 η 本身。**这不是 O 的精确公式**：O 还加 Lovász，使用逐 anchor 加权均值和粗 GT，且只更新受限的共享神经网络。

对实际逐 anchor 的 CE，令 V_s 为某一 anchor 在五时域合并后的有效粗标签位置，N_s=|V_s|，G_s 为正例数，D_s=N_s+4G_s。固定一个 decoder 层，其经验风险是

```
R_CE = E_s [ Σ_{j∈V_s} w(y_sj) · ℓ(p_sj,y_sj) / D_s ]。
```

为了分析这个表达式，假设 N_s>0，定义一个辅助抽样分布 Q：先按训练 anchor 分布抽 s，再在 V_s 中均匀抽 j；这只是重写风险，不是改变 loader。X 表示可用观测、空间位置和时域，不含 GT。对相同抽样规则下的总体风险有

```
R_CE = E_Q [ a_s · w(Y) · ℓ(p(X),Y) ]，a_s=N_s/D_s。
A(x)=E_Q[a_s Y | X=x]，B(x)=E_Q[a_s(1−Y) | X=x]。
仅此风险的非受限逐点极小值：p*(x)=5A(x)/[5A(x)+B(x)]。
```

只有额外条件使加权条件分布与 Q 的自然条件分布相同时，才可把它简化成上面的 5η/(1+4η)。具体条件可写为 E_Q[a_sY|X]=E_Q[a_s|X]η_Q(X)，例如给定 X 后 a_s 确定或与 Y 条件独立；此时 η 仍指 η_Q，不是完整评测的自然体素概率。这里 a_s 取决于整个 GT 的前景支持，而完整评测又使用另一个测度：所有原分辨率有效体素的混淆计数，且四个未来时域分别算比率后等权平均。实际 O 还将三层 CE 相加并加入三层 Lovász，参数共享，故没有逐层独立达到上述极小值的保证。“CE 是 proper loss，所以 O 已得到校准概率”不成立；也不能机械地用除以 5 的 odds 变换来证明 O 已校准。

这些推导不建议改变当前判决。论文中的 J* 是同一测度下单个总体 pooled Jaccard 的未知最优效用，不是我们测到的 14.664%。即使假设四个时域都能独立实现 Bayes 决策，也应各自对应 J_h*/(1+J_h*)；共享有限网络不满足这种独立自由度。把本项目的宏平均实测值直接代入当共同新阈值，会混淆未知最优值、聚合方式、当前模型成绩及验证集选择。

## 对下一阶段的约束

完整结果首先回答是否确实超过 M0。如果保持提升，O 是新研究必须超过的强控制。机制研究需同时区分“表征如何变化”和“已有分数如何变成前景判决”，不能仅用 IoU 或 pooled FP 的变化证明动力学变好。

当前 full 输出只保存来源、每样本混淆和哈希，没有完整概率或体素排序；因此不能在完成后从这些记录补造校准曲线、PR 曲线或表征相似度。若要研究这些量，应另冻结诊断样本与计算预算，并与主评测分开记录。任何事后分析都不改变正在运行的四模型、原生 argmax 或完整验证判据。
