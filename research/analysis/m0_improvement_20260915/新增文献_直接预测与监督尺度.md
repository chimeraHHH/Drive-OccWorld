# 把预测结构、监督测度和训练支持范围分开研究

2026-09-15。在 F/O 固定训练等待期间新增两项原始文献阅读，并只读检查作者代码。没有部署新模块、安装依赖、下载模型权重或启动额外训练。

## 两项文献及其适用边界

**Beyond Myopic World Models（2026-08 预印本）**讨论把初始观测和行动序列直接映射到远期终点，以终点损失训练；其控制实验还让循环基线采用相同长时域目标。实验是连续状态控制和 Pong 的 MSE。文中的直接预测误差界仍含随时域变化的函数逼近误差，不能据此保证新架构一定更准。[作者论文，§2–3](https://arxiv.org/html/2608.07420v1)

对本项目的判断：M0 的现有重放已经在四个未来时域训练，末时域梯度也能传播经过全部生成状态。因此不能把“补上长时域监督”说成我们的新方法，更不能拿该论文的一步训练缺陷直接诊断 M0。真正未辨识的是，在当前已有 BPTT 的前提下，**联合预测多个未来状态是否比串行状态更新更容易学习**。这种比较需要控制损失、数据覆盖和可训练容量；改变结构后零更新性能明显掉落时，也需计入预训练迁移的影响。

**SparseWorld-TC（v3，2026-04）**使用稀疏点组、观测特征及轨迹条件联合预测未来；以几何匹配和分类学习。它在 Occ3D 上评价语义 mIoU/几何 IoU，采用更长训练与不同输入/网格。本次读到的 v3 随机未来长度消融为 1–8 秒平均 mIoU 20.36→22.33，不能误写成 20.36→25.60 或对照我们的 GMO 分数。[作者论文，§3–4](https://arxiv.org/html/2511.22039v3)

对本项目的判断：这提供了“改变预测结构”的可实现参照，但整网更换同时改变观测编码、空间表示和监督，无法直接解释当前 M0 的瓶颈。它的数字不构成我们应达到同一分数的证据。现阶段不因新论文分数高而中途停止 F/O。

## 实际代码检查：哪些能借鉴，哪些不能直接移植

论文里的旧代码链接返回404；已找到同作者的[可用仓库](https://github.com/MrPicklesGG/SparseWorld-TC)，固定到 commit `8ef331da491f0c2c317d3d6cf3e21a9c8a1576be`。仅检出十个文本源文件，摘要见 `literature_sources/direct_prediction_source_receipt.json`。仓库与旧文献中的 `MSunDYY/SparseWorld` 是不同项目。

- `models/sparse_world_transformer.py` 的 decoder 将相同初始 query 按未来帧展开，添加时间 embedding，并用展平的 4×4 `fut2cur` 调制特征。层内把 `FT×Q` 合成序列做 attention，然后精修点组。这是联合未来查询的真实代码路径，不是递归生成上一帧再继续。
- `configs/sw-tc.py` 当前是 600 queries、8 帧视觉历史、17 类、0.4m 网格及 `[0,2,4,6]` 时间索引；相机可用、雷达关闭。这些设置均与我们的原生雷达输入及完整细粒度 GMO 标签不同。
- 不能将它的联合 attention 原样放在 M0 的全部 40,000 BEV cells 上：四未来会形成 160,000 个 token，标准稠密注意力需要处理 256 亿个两两关系/每头。即使实现节省显存，关系计算规模仍不同。若以后使用这种结构，必须先明确 token 表示/采样及与完整原任务输出的连接。
- `sparse_world_head.py` 实际用双向近邻配对、加权 SmoothL1 与 Focal，并保留逐层监督和特殊点权重。不能把论文的简写目标直接等同于“仅两个未经加权的 loss”，也不能把其几何损失直接替换 M0 原目标后仍称控制变量比较。
- 作者[权重目录](https://huggingface.co/MrPicklesGG/SparseWorld-TC/tree/main)列出 small 权重。官方模型仍按用户约束仅评价；本次没有下载或运行它。将来若借用机制构成自己的候选，需独立说明原任务适配及训练范围。

## 当前真正值得推进的科学问题

当前证据更适合组织成三个可区分的轴，而不是堆一串网络模块：

| 轴 | 当前证据 | 能改变下一行动的结果 |
|---|---|---|
| 监督如何分配误差的重要性 | 原粗化改变前景块的监督；少量前景 anchor 的 scaling 梯度很大；训练 surrogate 下降没有带来任务收益 | F/O 的固定最终比较以及同更新组的裁剪日志，区分分辨率和损失组成线索 |
| 未来状态如何被预测 | 双槽和当前参考帧改造未获益；原四步梯度链确实连通 | 只有基本目标可学、且收益受制于远期预测时，联合未来查询/未来观测表征监督才成为有依据的结构干预 |
| 训练是否覆盖目标分布 | 当前仅512个不同 anchors，观测编码固定；这是适配筛查 | 正候选先在完整5119上确认；若训练与开发行为分离，再增加训练场景支持范围，而不是反复看同一开发集改超参数 |

F/O 若改善，也只是证明某种监督设计对这个模型/预算更有效。达到高水平论文需要进一步提出、验证可迁移的机制，例如“逐 anchor 的归一化怎样改变世界模型对稀疏状态的更新分配”，并与联合未来预测、另一表示或真实输入退化建立有控制的联系。不能预先把这种尚未验证的机制写成结论。

本次阅读没有发现可以不改任务、不做适配就保证超过 M0 的现成模块。当前优先顺序不变：完成 F/O → 固定候选与完整原任务验证 → 再据真实效果和失败类型选择结构或数据覆盖实验。
