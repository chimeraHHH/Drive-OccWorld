# 损失、决策规则与评价聚合：补充文献核查

2026-09-15。读取了两篇作者 arXiv 全文的方法/指标段及作者仓库说明；未安装代码、修改阈值或评价协议。

[RankSEG，Dai 与 Li，JMLR 2023](https://arxiv.org/html/2206.13086)，§1–2、§4.2：研究条件概率估计与 Dice/IoU 决策的一致性。其目标是逐图比值的期望，Bayes 规则使用条件独立假设；不能把分类概率估计和分割决策自动视为同一问题。正式出版信息见 [JMLR](https://www.jmlr.org/beta/papers/v24/22-0712.html)。

[RankSEG-RMA，Wang 与 Dai，2025](https://arxiv.org/html/2510.15362)，§2.1–2.2、附录 B：通过近似降低原决策规则计算成本，并明确区分图像级与数据集级 IoU；文章直接说明，优化前者可能降低后者。作者提供[代码](https://github.com/ZixunWang/RankSEG-RMA)。本轮未运行或核实其在本任务上的性能。

对本项目的推论：我们的主指标是每个未来时域先跨样本池化混淆矩阵，再算 GMO IoU，最后平均四个时域。它不同于上述逐图 IoU 目标；未来占据的体素依赖、原加权 CE 和 scaling 产生的概率也不自动满足理论条件。因此这些工作提供目标定义和已知方法边界，不能直接变成我们的增益保证或新颖性。

当前实际行动仍是两个独立训练干预：F 只改完整分辨率监督，O 只取消 sem/geo scaling 的优化贡献；原 argmax、完整 GT、主指标和 M0 对照不变。O 保留原加权 CE 与 Lovász，也不是自然分布下的纯 proper NLL。若未来研究输出决策或可靠性，须另列明确对照；不以换评价聚合、后处理校准或别任务论文分数宣告学习到的未来模型优于 M0。
