**一个真实边界需明确：**full 协议中的 `nomination_rule` 是开发集晋级规则：对 M0_fp32、C 两项点估计均 ≥0.5 pp 且各自区间下界 >0；它已机械选出 O。完整验证沿用 0.5 pp 作为实质效应参照，但没有名为“full 自动 pass”的冻结字段。不能伪造该字段，也不能看到结果后改成下界 >0.5 pp、每时域不降、t0 不降或 2×2 必须阳性。最终 goal 状态由全部真实证据与用户原目标整体审计。

## 结果到达后的直接规则

先等完整四模型 M0/M0_fp32/C/O 的 5,119 条共同样本、150 场景和既定严格汇总证据全部通过。未完成或证据不一致，只能判为结果尚不可用，不能把缺失样本当负结果，也不能截取已完成部分判胜。

主量固定为：各未来时域先池化全部完整 GT 混淆矩阵，计算 class1 GMO IoU，再平均 0.5/1/1.5/2 秒。设 δB=100×(JO−JB)，B 为 M0_fp32 或 C，单位 pp；LB/UB 为既定场景配对 95% 区间。它不是五时域平均、全时域先池化的 IoU，也不是 binary mIoU。

| 完整结果 | 允许的结论与下一行动 |
|---|---|
| 两项 δ 均 ≥0.5、两项 L 均 >0 | 支持开发阶段实质幅度在完整原任务上的复现；O 可成为后续更强控制，原 M0 与 C 保留。再由根任务整体审计“超过 M0”的目标是否完成；不能自动升级成 ICLR 创新或泛化结论。 |
| 两项 L 均 >0，但至少一项 δ <0.5 | 如实报告“正提升，但未在两项比较上完整达到既定实质参照”。小提升不是无效，统计显著也不能替代效应大小；不据此自动扩预算或降低参照。 |
| 只稳健胜 C，未稳健胜 M0_fp32 | 只能支持改善原目标延续训练的结果，尚不能支持超过冻结基线。反过来只胜 M0_fp32 而未胜 C，也不能证明目标干预优于匹配延续训练。 |
| 任一主区间包含零 | 对该比较方向仍不确定；不要将其写成“没有效果”。若其 U<0.5，可另说明区间未支持既定幅度；若 U≤0，才有更强的非正方向证据。全部固定结果照报。 |
| 完整收益收缩或转负 | 优先对照开发采样与完整场景组成、前景支持量、FP/FN，作为事后诊断。不得通过删除场景、改阈值、换时域/指标或提名 hybrid 挽救成功结论。 |

## 三项容易误读之处

**比较和 t0：**M0_fp32 是同数值条件的主参考，C 区分目标干预与普通延续训练；原生 M0 及 M0_fp32−M0 必须同表。若精度差足以改变排序，只能明确说“超过同精度参考”，不能借它笼统声称超过原 M0。t0 与四未来时域全部披露，但 t0 不是新增否决门。开发 t0 的 O−M0_fp32=−0.15914 pp，O−C=+0.08517 pp；完整结果应重新报告真实值，不能将前者归因为相对 C 的目标损害。

**场景和曝光：**冻结 selection 实际为 18 个场景各33条、95个各34条、37个各35条，总计5,119条。每次抽150个场景，有放回地保留每个被抽场景的全部 anchors 后汇总混淆；不是每场景两条，也不是等权平均150个场景 IoU。完整集包含开发场景，文件中的历史 `locked` 标签不构成新盲测证明。10,000 次配对区间仅描述固定模型的场景抽样不确定性，未调整多重比较，也不包含训练 seed 或先前选择的不确定性。

**后续科研：**若实质收益保持，先研究训练风险与最终多时域评价的对应，并区分损失组成、总体尺度/裁剪及共享参数的时域取舍。若收益未保持，先解释覆盖与误差差异，再决定是否扩大训练分布；不重启已否定的有限预算坐标/双槽路线。已冻结 C/O 2×2 只能提供固定模块替换效应，受潜空间共同适应限制；无论其结果如何，都不改本页主量、比较、参照或 full 候选。删减既有 loss、现成未来特征监督及单一历史 validation 上的提升，本身均不足以构成 ICLR 新颖性。
