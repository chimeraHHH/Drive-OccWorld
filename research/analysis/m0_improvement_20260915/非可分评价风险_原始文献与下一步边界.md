# 非可分评价风险：原始文献与下一步边界

2026-09-15，继续补读原论文；不使用 skill，不据此新增训练。当前 O 的真实开发结果只支持进入完整验证，不能把已有目标函数删减包装成新方法。

## 已有工作已经解决了什么

**Berman et al., CVPR 2018，Lovász-Softmax。** 原文明确区分 image/batch IoU 与 dataset IoU，并讨论缺失类别为何使两者不同；提出仅对 batch 中出现的类别计算对应项及 equibatch。因而“逐样本 IoU 与全数据池化 IoU 不等”既不是新观察，也不能单独作为本项目的新颖性。我们实际仍使用其 loss，必须检查具体调用中类别处理与聚合层级。[原文](https://arxiv.org/html/1705.08790)

**Narasimhan, Kar, Jain，ICML 2015。** SPADE/STAMP 分别处理两类非可分性能函数，采用自适应线性化与随机更新；Jaccard 已在其伪线性指标范围。它的线性模型、奖励函数与收敛假设不能直接移植为深度占据主干的保证。“引入一个全局 IoU 状态变量”本身也不能视为新算法。[原论文](https://proceedings.mlr.press/v37/narasimhana15.pdf)

**Bao and Sugiyama，AISTATS 2020。** 研究线性分式效用的校准 surrogate；给出条件性校准分析，并用两个独立样本组构造分式梯度方向分子的估计。需要区分未归一化估计的无偏性、随机方向再归一化，以及特定函数空间下的优化结论。它不是“普通 soft-IoU + AdamW 已具有一致性”的证明。[论文与正式出版信息](https://proceedings.mlr.press/v108/bao20a.html)

**Sanyal et al.，Machine Learning 2018。** 已补读公开预印本全文与附录，并核对作者 DeepPerf 仓库的固定版本。DAME 已研究冻结下层表征后优化单一线性分式目标；当前 AdamW/Lovász 与四时域比率均值不能直接继承其保证。详细算法定位、证明条件及作者实现与论文的差异见 `sanyal2018_nondecomposable_card.md`。[作者预印本与出版记录](https://arxiv.org/abs/1802.00086)

## 本项目推导：四未来平均不能偷换为单一分式

这里的推导针对一个可微 soft-confusion 替代量，不是硬 argmax GMO 的可微性或统计一致性证明。令 I_h(theta)、U_h(theta) 是按原有效标签范围、在目标数据分布上汇总的 soft intersection 与 union。每个 U_h>0 时：

```
J(theta) = (1/4) sum_h I_h(theta) / U_h(theta)

grad J = (1/4) sum_h
         [U_h grad I_h - I_h grad U_h] / U_h^2
```

一个分式单独优化时，其分母平方只是该时刻正标量；但四个时域相加时，这四个标量不同。直接把每个分式的梯度分子相加，会重新加权时域，不再是原登记主指标的梯度。因此不能把上述单指标论文的方向估计原样套用，再声称对齐我们的 future macro GMO。

同样，两个独立样本组的乘积估计要求相应独立性；同一个场景的相邻 anchors、同一 anchor 的大量体素不能被轻率当作独立抽样。有限 buffer/滑动均值和当前模型之间存在滞后与相关性，要区分实用估计器、偏差控制和已经成立的理论。真实 evaluator 以全部有效体素计数池化，简单按每张图前景量归一化又会改掉目标测度。

## 下一轮工作应回答的问题

首先完成 O 与 M0/M0_fp32/C 的完整同样本验证，保留 t=0 下降、未来各时域以及 FP/FN 代价。若完整改善成立，O 应成为更强的实验对照，而不是直接宣布论文方法完成。

随后要区分三个可检验解释：原目标的相对风险权重是否不合任务；整体尺度和裁剪/AdamW 交互是否主要起作用；当前与远期共享参数是否造成任务间权衡。新实验应让各比较只改变被检验的因素，并在看结果前约定预算和判据，继续单 seed。当前 F/O 两臂不足以分离这些解释。

对最后一项尤其要保留对照：t0 的 O−C 其实为 +0.08517 pp，而 O−M0_fp32 才是 −0.15914 pp；不能把后者写成删除 scaling 项造成的当前退化。共享参数提供可能的影响路径，并不直接证明梯度冲突。另见 `O改进的概率与决策边界.md` 对原类权重、逐 anchor 归一化与已知 Jaccard 决策理论的推导。

更大尺度的研究价值取决于能否提出有明确估计对象的多时域风险、揭示其在稀疏支持和传感器信息变化下的行为，并超过 CE+Lovász、现有非可分指标优化及合适的结构基线。上述三条目前都是待检验的问题，不是我们已经实现或证明的贡献。
