# 统一状态坐标与监督的下一轮研究计划

2026-09-15；独立设计建议，所有效果判断均为待验证假设。本次只读本地源码、既有文献收据及 `diagnostic_runner` 的坐标审计；未修改训练实现、未启动实验、未连接服务器。

**建议先进行两条件比较：原生单槽 continuation（C）与全程 t0 参考系单槽预测（A）。保留冻结 M0 的同精度评价作为效用基准。第三条件 B 是未来局部坐标状态加明确输出对齐，但须先解决完整评价 ROI 的覆盖与额外计算混杂；不为凑齐三臂而运行会丢失评价区域的 B。未来教师先明确契约，不能与首次坐标干预一起加入。** 研究问题是：给定相同可用信息和监督，显式几何对应是否增加了模型必须学习的补偿负担，以及一致的状态空间能否改善真实未来占据预测。这个问题不是“末端加一次 warp 能不能涨点”。

## 1. 已知证据、待核事实和撤销条件

[坐标审计](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/coordinate_contract_audit.md)与[四组几何反例收据](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/coordinate_contract_proof.json)已核实本地来源：`LoadOccupancy` 将各未来时刻的源占据转换到当前观测 LiDAR 系 R；未来 query 采样采用 `future2ref × ref2history`，生成状态按未来帧变换入队；逐 token 输出头、原生 loss 和 evaluator 未加入 ego 依赖的空间输出 warp。静止点遇到自车 +x 2 m 时，GT 仍在 R 的原位置，显式零偏移对应则在未来局部网格移动 2 m。真实数据历史为 2 帧、latent memory 为 1 槽，两者不可混用。

这证明**显式对应先验与监督索引不一致**；没有证明训练后 logits 属于未来坐标、旧 checkpoint 错误或全部旧实验失效。Deformable offsets、action/ego 调制及逐层特征能够学习补偿；监督本身也会塑造 token 语义。神经网络没有被几何注释强制为等变表示。

在新训练前，以事先按 token 规则选择的 2–4 个官方 train 记录完成低成本事实核对：一例近静止 ego、一例非零平移、一例转向；若缺某类，明示缺失。核实际源 `.npy` 的局部坐标合同、七帧 token/时间顺序、第 2 帧 anchor、loader 转换后的 voxel 索引、attention reference points，并补齐服务器 helper/source SHA 与审计版本的一致性。选择不得根据模型预测好坏。现有 AST phantom 只验证源码几何，不代替这项真实数据核验。

**撤销规则：** 若实际 source/data contract 表明 GT 原本已在未来帧，或运行时存在此前遗漏且生效的输出变换，撤销本坐标不一致假设，停止据此修改模型。若几何合同确实如此而 M0 学会补偿，则保留源码事实，撤销“该差异是主要性能瓶颈”的强解释；仍可检验降低补偿负担是否有训练收益。

## 2. 两个必要条件与一个有条件的几何对照

固定数据/损失/评价：同一 M0 epoch24 参数、native radar 与冻结观测编码缓存，单训练 seed11，单槽，完整 `future_pred_head` 可训练；原生所有未来时域、所有中间层任务损失及类权重保留。C/A 使用相同 optimizer、更新数、有效 batch、样本顺序和精度；不同时加入持久记忆、motion branch、重加权或教师。原始 M0 与同精度冻结 M0 是零更新参考，不算新训练臂。旧 pilot continuation 只有在源、精度、数据顺序、优化和总曝光完全一致时才可复用为 C，否则重新匹配。

| 条件 | 状态和监督合同 | 可以识别的差异 |
|---|---|---|
| C：native1 continuation | 保留原显式采样/队列变换和原任务损失 | 控制继续训练本身，必须能原生回放 |
| A：reference-state | 所有预测 query、位置编码解释、生成 memory 的空间索引均属于 R；输出直接与原 R 系 GT 对应 | 相同模型容量下，改变全程显式空间对应；检验其任务价值 |
| B：future-local-state（条件性第三臂） | 每个生成状态属于自身未来 ego/LiDAR 系；按真实相对位姿读取历史；输出经明确几何算子回到 R 再计算同一原生损失/评价 | 检验一致未来局部状态是否也有效，区分“保持固定坐标”与“一致合同” |

### A 必须改变完整空间合同，同时保留动作信息

以列向量写，所有 A 状态 `F̂_h^R(x_R)` 都在 R 中。读取 R 系生成状态时对应为 `x_memory=x_R`；若日后读未重投的历史观测槽，则用该槽真正的 `T_(R→k)`，不能把所有原始历史也冒称 R。当前单槽 F0 已是当前观测参考系，因此首次与后续生成槽的空间矩阵均为恒等。保留 horizon/time identity，generated memory 的**时间身份**不会因空间系固定而变为 t0。

实现合同至少覆盖：cross-attention reference points、self-attention query 坐标解释、位置编码索引、memory 的 frame metadata、每步生成状态入队和全部 decoder 输出层。查询表仍从 M0 原权重开始；不额外换成 F0 初始化，否则又改变预测结构。原 GT、label downsample、logit resize、argmax 和有效评价区域完全不变。

**关键解耦：** 当前 [detector:509](/Users/yiminghua/2026Summer/WorldModel/dropple/code/Drive-OccWorld-sota-p2/projects/mmdet3d_plugin/bevformer/detectors/drive_occworld.py:509) 共用了 `future2history` 作为几何路由结果和 ego 条件；[ConditionalNorm:236](/Users/yiminghua/2026Summer/WorldModel/dropple/code/Drive-OccWorld-sota-p2/projects/mmdet3d_plugin/bevformer/modules/conditionalnorm.py:236) 将其编码为 gamma/beta。A 必须把“状态空间基底”与“各状态时刻的真实自车相对运动”分开记录：空间路由固定 R，ego/action 输入保留与 C 完全相同的物理位姿、原基底和数值。若把条件矩阵也全置 I，就同时删除了运动信息，不能识别坐标效应。原条件允许的未来 ego 信息继续明示；这不是无未来动作输入的预测任务。

### B 不是直接对旧 logits 盲加 warp

令 `T_(R→h)` 把参考坐标变到未来局部坐标，B 的连续输出满足

`L_h^R(x_R) = sample(L_h^h, T_(R→h) x_R)`。

对 logits 而不是 argmax 标签做确定性可微重采样，所有参与任务监督的 decoder 层都应用同一合同；梯度须从原 R 系任务损失穿过对齐算子到未来状态。先明确运算在输出原生网格/训练下采样网格/评价网格之间的顺序，避免无意增加两次平滑；单位变换须还原 C 的轴序和 resize 路径。仅有 2D height-collapsed BEV 时，平面 SE(2) warp 不能声称等价于完整 SE(3)，roll/pitch/高度通道需要在显式 3D 场上处理或把近似写明。

**完整 ROI 是阻断项。** 对原 R 系评价域 ΩR，B 未来表示的支持集必须覆盖 `T_(R→h) ΩR`，并包含插值边界。相同大小的未来轴对齐 ROI 在平移/转向时通常不够。不能把出界 GT 改成 ignore、缩小评价 mask，不能以边缘复制或默认背景填充声称几何对齐已经正确。原 loader 还会 `np.clip` 出界占据到边界，因此边界不是可以顺便删除的“噪声”。覆盖/边界分层只能作为补充诊断，主指标仍计算完整原任务。

扩大 B 网格并保持分辨率会增加 token、计算甚至位置表参数；保持 token 数则改变分辨率。两者都须报告，不能叫“仅改坐标的等容量对照”。如果不能在预算内公平匹配，B 先停留在几何与覆盖可行性测试，首轮只训练 C/A。把 R 的规则网格映到未来坐标、继续按 R 索引输出，可作为坐标换基的等价性检查，但它实质上接近 A 的另一种参数化，不应另计为独立 B 成功。A/B 即使都成功，离散插值和位置编码差异仍使它们不是严格等价的神经模型。

## 3. 先行检验与 M0 初始非 parity 如何解释

按下面顺序执行，先测成本再冻结训练预算，不据开发分数调候选：

1. **几何路由门：** 保留已有四组 phantom，补真实 train pose 的单 voxel/静止场对应；零 offset 是独立几何诊断，不是将 M0 的 offset 参数清零后宣称模型效果。A 在非零 ego 时应保持 R 中静止点索引；B 先正确读未来局部坐标再回到 R。身份变换、组合/逆变换、XY/Z 轴序和 cell-center 均有明确误差容限。
2. **运行/梯度门：** C 同源回放须与 M0 同精度结果一致。A 在全 identity pose 的隔离测试应与 C 相同；B 在 identity 下不得引入额外平滑。A/B 在真实非零 pose 下不要求初始 logits parity；完整未来损失须更新 transformer，最后时域梯度能到达更早生成状态，标签分支无 forward 输入。
3. **固定小 train 集可学习性：** 2–4 个不同场景短运行只检查原损失、前景预测、梯度与实际耗时。C/A 都更新同样次数，不挑最优 checkpoint。记录更新前后真实任务指标，禁止用开发集选择“有利的初始 warp”。

改变空间路由后，同一参数值对应的函数已经改变；M0 曾学到的 ego 补偿可能暂时过度修正，因此 A/B 零更新成绩下降不否定一致表示。同样，零更新上升也不能证明重新训练更好。**非 parity 的诚实含义是暖启动的分布/函数变化，需要再适应。** 首轮不只给 A 单独重置 offsets/加训练步，也不把 512 小集短训的失败解释为所有一致坐标路线失败。若 A 初始冲击大但持续学习，增加数据覆盖并给 C 同样预算；仅在适应曲线和足够覆盖后讨论效果上限。无需为此立即从头训练整网。

## 4. Future-teacher 的后续契约（本轮不叠加训练臂）

未来表征监督要回答的是中间预测状态是否受到了足够、正确配对的几何监督。它已有先例，必须放在坐标合同通过后的下一次独立比较中，不能用它掩盖本轮坐标效应。先保留 C/A 的原任务损失，决定采用哪种状态表示后再比较该模型有/无教师，匹配全部其他条件。

教师契约需逐项冻结：

- **时刻与来源：** 每个 `(scene, anchor, h, target_token, timestamp)` 对应真正未来帧。冻结 teacher 的 checkpoint/全部参数，eval 模式，无 BN 状态更新；teacher 特征是 train-only target，使用 `no_grad` 并在特征变换后显式 detach。若 teacher 用未来雷达、深度或 LiDAR，而不只是未来图像，单独列为 privileged supervision，不能藏在 native cache 中。
- **表征层：** 最优先使用与 student 状态能明确匹配的物理表示。A 的目标是未来世界状态在 R 的特征 `Z_h^R`；B 的目标是未来局部特征 `Z_h^h`，输出仍回到 R 做原任务监督。两个同形状的 BEV 数组不是天然配对。
- **坐标：** A 可在 R 的查询网格中，用未来帧的正确外参重投图像并构建教师；或先得到有显式 3D 坐标的未来局部特征再变换到 R。当前 native 2D BEV 隐含高度/视角，直接 bilinear SE(2) warp 只能作为近似，不能称完整 3D 几何真值。若暂时无法形成可核验 latent 合同，应先做明确 3D 占据 soft-target 监督，称作输出蒸馏，不冒称潜状态几何监督。
- **动态物体：** 未来帧对齐回 R 是 ego 坐标转换，应保留物体在未来的真实世界位置；不要再把未来物体反移到当前位置。未来可见性、teacher 缺测和不同 ROI 的覆盖仅决定辅助损失支持，绝不更改原任务的 loss/eval mask。
- **损失与梯度：** 对齐后目标与 student 由清楚的固定或可学习 adapter 比较，adapter 参数计入训练范围。teacher 端梯度为 None；student 的未来状态和其递归上游保留梯度。损失按固定 scene/horizon/有效辅助位置归一化，权重及特征归一化只从 train/preflight 定义。不能拿 dev 选择 teacher 层、错时配对或辅助权重。
- **测试隔离：** eval 数据加载器不读取未来图像/teacher cache；删去或置乱训练目标文件时推理 logits 不变。原基准明确允许的未来 ego/action 仍可用，但不得把未来 teacher latent 填入生成 memory，即使 detach 也算前向泄漏。

## 5. 从 512 screen 到真实训练分布

现有选择是 256 个官方 train scenes×2 anchors；4 passes 是 2048 次样本曝光，accum4 时为 512 个 optimizer updates。它不是 2048 个独立样本，不是完整训练集的 4 epochs，也不是 5119 全验证训练量。512 screen 用于排除明显失配/估计方向，不能给出通用无效结论。

先用两臂真实 preflight 计量：缓存每 anchor 空间、完整四时域前后向的稳定/尾部耗时、评价耗时、峰值显存；预算包含新增缓存、训练和最终完整评价。C/A 共用 F0 缓存，不反复运行冻结视觉骨干。B 或教师若增加表示/缓存成本，须先单独实测，不能沿用 A 单步估计。

扩展的第一优先级是**唯一 train 场景与合法 anchor 覆盖**，再增加重复曝光：按固定 seed11 顺序纳入所有可用官方 train scenes，按合法 anchor 自然分布采样，不以模型成绩筛样。每 scene 少量 anchor 适合覆盖筛选，但最终若目标是原生 dataset 风险，训练采样需回到完整合法 anchor 分布；scene 等额采样与原生 anchor 均匀风险不同，不能悄然互换。为省存储可按固定不重复批次逐步缓存、训练并淘汰有收据的临时缓存，所有臂同顺序同曝光。

预注册两类事实：scene/anchor 数、ego 位移/转向和前景支持的覆盖；以及每臂有效更新数、训练/开发曲线。train 持续改善而 dev 下滑时，先扩大场景覆盖，不能只在 512 集上刷更多 epoch。train 本身不改善时先查梯度、尺度和适应，不应拿 full5119 评价充当修复。若曲线尚未充分学习或区间宽，允许一次预登记的扩大覆盖阶段，C 同步扩大；不因“未显著”直接否定机制。

开发集继续使用固定官方 val scenes，和全部 train scenes 不交叉；相邻/重叠时序片段不跨 split。开发暴露和历史 val 暴露如实披露。模型、checkpoint 和阈值规则冻结后，再在完整合法 full5119 上同样评价 M0、C 和候选。full5119 含开发场景，因此是原生验证全量确认，不是新的盲测集。后续若面向 ICLR，要增加独立任务/主干或真正独立评价协议，而不是把已暴露 val 改名 test。

## 6. 预注册比较与可被否定的结论

主效用同时看候选−冻结 M0 和候选−C 的四个未来时域原生 fine-GMO 指标；以原 evaluator 定义为准，t0 单列不混入未来均值。报告各时域、FP/FN、自然风险和固定模型的场景配对区间。建议事先用 **+0.5 percentage point** 作为是否值得继续投入的实用量级，而非观察结果后采用；它是决策阈值建议，当前尚未冻结。不得用重调阈值/auxiliary 特征距离代替原任务提升。

| 观察 | 可支持的解释与下一步 |
|---|---|
| A 优于 M0 且优于 C，覆盖充分；B 也同向 | 支持一致空间合同具有实用价值；尚不能把全部增益归为一种唯一中介，也不是通用新颖性证明 |
| A 只优于 C，但仍不及 M0 | 同预算机制方向可取，实际改进目标未完成；若适应/覆盖不足则扩大，若充分则止损 |
| C 上升，A 不优于 C | 目前收益来自 continuation；保留更强 C，勿把继续训练的收益归坐标 |
| A 成功、B 失败 | 先排查 B 覆盖/插值/初始化，不足以证明未来局部表示错误或固定坐标唯一正确 |
| 几何事实成立，但 A 充分学习后无有意义收益 | 否定本预算/模型的主要性能瓶颈解释；不否定源码对应事实。转向独立的未来表征监督或直接目标时域预测 |
| 两臂训练不足或场景区间过宽 | 信息不足；不能写“坐标不重要”或“所有任务连接路线失败” |

可补充固定 ego 位移/转向分层、远近时域和 ROI 边界分层；分箱在训练元信息中定义，不能看 dev 成绩找显著组。高 ego 组收益更大只是符合机制预测，还可能混杂速度、可见性和场景难度。GMO 是可移动语义类别，包含停放车辆；只有有可核实运动标签时才称“实际动态对象”。保持原主指标之外可做合成静止场检验，但不能用它替代实际占据成绩。

单 seed11 可以证明固定训练方案在这些评价样本上的真实提升；场景 bootstrap 不证明跨训练随机性稳定。达到“超过 M0”至少需要真实 checkpoint、原生全量评价、相对同预算 C 的增益和可审计来源。若置信区间不能排除预登记的实用增益，只能说未定；跨零不是等效证据。

## 7. 文献先例与 ICLR 边界

- [ForecastOcc，ICRA 2026](https://arxiv.org/html/2602.08006v1)已经使用冻结未来图像教师与未来状态损失，且每个 horizon 从观测上下文独立合成；[作者实现](https://github.com/robot-learning-freiburg/forecastocc/blob/79a4194c3a060450da2b779f55c3b4a335d35d38/mmdet3d/models/detectors/forecastocc.py#L407)的 FSA 在图像特征栅格比较，并非完整 3D SE(3) 对齐。不能把“增加未来特征监督”当新贡献，也不能原样相减我们的异坐标 BEV。
- [SparseWorld，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/37347/41309)将多时域未来 GT 统一到当前坐标、递归融合预测与观测产生的查询；“统一坐标”“持续观测查询”已有先例。其语义占据与稀疏表示不同，不能移植外部 mIoU 作为本实验效果依据。
- [OccSim，2026](https://arxiv.org/html/2603.28887v1)已有 ego warp 与几何生成约束，但主条件含初始静态 GT occupancy、动态车辆另处理，不能作为相机/雷达未来 GMO 的直接方法上界。刚性对齐本身是既有几何操作。
- [GEM，2026](https://arxiv.org/html/2605.17682v1)说明直接查询未来状态是可竞争的结构；若一致坐标也无效，应把直接目标时域预测纳入后续强对照，而不是无限扩充生成记忆。

当前 M0 训练已经滚动使用自己的生成状态，不能仅凭时域下降称为典型 teacher-forcing exposure bias。坐标清理、一次 warp、一个 FSA 或单配置涨点都不足以独立构成 ICLR 贡献。潜在科研方向只能暂定为：**研究状态空间、观测证据和监督坐标之间的兼容性如何改变信息利用与样本效率，并提出在多个预测结构中可检验、在何种条件下失效的原则。** 先由 C/A 判明它是否值得继续；若实证不支持，应公开撤销性能瓶颈叙事，保留更强 M0/continuation 并转向其他假设。
