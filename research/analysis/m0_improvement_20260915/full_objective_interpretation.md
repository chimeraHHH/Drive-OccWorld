# O 完整验证集结果的独立判读

**已经建立的结论：在固定原生任务、完整 5119 个共同 anchor／150 个场景上，O 的未来四时域 GMO 超过原始 M0、同精度 M0 和同预算继续训练 C；这次改进不只存在于 development200。** O 可作为后续研究的更强对照，同时保留 M0 与 C。该结论限定于已固定的模型、单训练 seed 11 和这套曾被研究使用的验证数据，不等于已达到 ICLR 发表要求。

本报告沿用结果揭晓前的[《full结果判读审查》](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/full结果判读审查.md)，未改变其规则。主指标是各未来时域分别汇总完整 GT 混淆矩阵、计算前景 GMO IoU，再对 0.5／1／1.5／2 s 四个 IoU 作算术平均；不是五时域平均、四时域混淆矩阵合并后的 IoU，也不是二分类 mIoU。以下分数用 %，差值用百分点 pp。

|---|---:|---:|
| 原始 M0 | 15.97238 | 13.94438 |

O 与 C 都从同一 M0 初始化，复用相同训练数据、样本顺序、512 次更新、AdamW／学习率／clip35；O 去掉 sem/geo 的优化贡献，仍监督当前及四个未来时域。这里支持的是该固定训练干预整体的收益，尚不能把收益唯一归因到某一种机制。完整评价没有重新训练、调阈值、使用 R4 校准或安装训练损失适配器。

O 相对**原始 M0**的直接点差为 **+0.80342 pp**；上表没有另给 O−原始 M0 的配对区间，不能通过相加已有区间伪造一个。原始与 FP32 参考的差异远小于 O 的收益，排名不变，因此本结果不是仅战胜了改变精度后的基线。C 自身低于 M0，O 同时超过二者，也排除了“只是相对一个继续训练后退化的对照显得更好”这一有限解释。

development200 中 O−M0_fp32、O−C 分别为 +0.75739、+0.92544 pp；全量对应增益为 +0.80294、+1.02015 pp，未出现点估计收缩。但两套样本有重叠，不能称作一次独立复现。两个全量主比较点估计均超过事先的 **0.5 pp 有意义幅度参考**，区间下界也高于零；事实上两下界还高于 0.5 pp，但这只是观测结果。开发集晋级规则不能被追认成新增的“full 自动 PASS”规则，0.5 s 单时域的 +0.45358 pp 也不是新增否决条件。

**未来收益伴随不同的误报／漏报变化，不能概括为全面减少错误。** 下表为 O−M0_fp32，全量逐体素计数；负号表示该类错误减少。

相对 M0_fp32，0.5 s 用更多 FP 换取更少 FN，1 s 两者都下降，1.5／2 s 则 FP 下降而 FN 上升；四未来合计 FP −26,205,756、FN −321,957，合计数不能掩盖远期漏报增加。相对 **C**，四个未来时域均为 FP 降、FN 升，合计 FP −96,713,587、FN +8,281,704。因而 O 对 C 的 IoU 收益并不是提高了前景召回；远期 IoU 增益更大也不能单凭这些计数解释成学到了更准确的运动传播。这里是体素分类误差，不能直接换算成目标级碰撞风险或安全收益。

**当前帧代价须按比较对象分开。** O−M0_fp32 的 t0 差为 **−0.13958 pp，95% CI [−0.16824, −0.10944]**；O−C 为 **+0.08814 pp，[+0.06946, +0.10805]**。因此 O 尚未恢复原 M0 的当前帧性能，但去掉 sem/geo 后相对同预算 C 的当前帧反而改善，不能写成“删损失导致 t0 下降”。当前与未来共享读出参数，且 t0 语义 logits 不直接回流未来状态；共享读出折衷、继续训练漂移及目标改变各自起什么作用仍未识别。t0 结果应披露，但不能事后把“t0 必须无下降”加入原未来任务主判据。

**机制仍未确定。** 已有同状态梯度分项证据表明，去掉 sem/geo 同时改变梯度方向与尺度；真实训练日志也显示 C 有 43／512 次超过 clip35，O 为 0／512。AdamW 的历史一、二阶矩与时变裁剪意味着这些差异不能简单视为可相互抵消的标量缩放。当前证据尚不能区分目标组成、全局梯度尺度／裁剪及优化路径分别贡献多少，也不能从混淆矩阵推出概率校准、排名或不确定性改善。详见[目标与优化器机制边界](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/O目标与优化器机制边界.md)及[当前与未来连接审计](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/O当前与未来预测连接审计.md)。后续 2×2 读出／特征诊断的 v1／v2／v2b 工程失败均已保留；v3 修复目录类型、部署清单及审计回执 JSON 表示后，**真实两 anchor pilot 已通过所有工程门**，耗时163.705 s、optimizer updates 0。初始化151.760 s，最慢 anchor 5.892 s；原冻结预算公式给 dev200 需要2388 s，超过1500 s 上限，因此服务器按预设规则停止（runner FAILED／returncode1，原因是预算门，非预测一致性失败）。没有进入 dev200，也未扩大预算或依据两样本分数作机制归因。详见[真实 pilot complete](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/server_results/campaign_readout_transition_v3/pilot/complete.json)与[资源停止记录](/Users/yiminghua/2026Summer/WorldModel/dropple/analysis/m0_improvement_20260915/server_results/campaign_readout_transition_v3/failed.json)。这项诊断是机制解释的后续工作；未获得 dev200 结果不改变已完成的 full 原任务改善证据。

**统计与发表边界。** 10,000 次 seed 11 配对场景 bootstrap 保留每个被抽场景的全部自然 anchor，并按上述主指标重新汇总；它刻画固定模型的场景抽样不确定性，不覆盖训练 seed、开发集选优或多次尝试的不确定性。没有多重比较校正；全量包含已曝光的开发／历史验证样本，不能称为盲测。F 未达到开发晋级门而未进入完整评价，完整五模型开发结果仍被保留披露；“未评价 F”不等于“F 得分为零”。这建立了一个值得研究的、可用更强对照：在现有架构下，简化辅助目标能改善原生未来 GMO。只移除已有辅助损失并取得单数据集、单训练 seed 的提升，还不足以支撑新的普适方法或 ICLR 级机制贡献；关键缺口是可判别的解释及其适用边界，而不是再把当前收益包装成新的融合架构。
