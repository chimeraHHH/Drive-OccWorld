## 构建过程中解决的问题

上游模块在导入时 JIT 编译 CUDA voxel renderer。第一次 CPU-only 构建未指定架构，无法从不可见 GPU 推断架构；第二次隔离构建遇到系统默认 GCC 超过现有 CUDA 支持版本。采用机器已有的 GCC/G++ 9、显式 `TORCH_CUDA_ARCH_LIST=8.6` 和独立 `TORCH_EXTENSIONS_DIR` 后成功。

没有放宽编译器版本校验，也没有修改系统编译器、环境包或 M1 代码。第一次尝试触及上游默认扩展缓存的构建准备；之后所有编译产物均在 M3 诊断目录隔离。8.6 只是本次构造验证的编译目标，未执行 GPU 算子，不能由此宣称 L40S CUDA 前反向已经测试。
